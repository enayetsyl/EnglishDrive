## Summary (read this first — 60 seconds)

This is the Class 4 cut of the drive. Grammar runs as a **cumulative remedial track in spine order, bottom-up**, teaching **the structures the Class 4 book/TG actually use, openly and by name**, plus a **small, depth-capped set of additions** that the school's own papers test and that genuinely fill gaps or serve as prerequisites — never additions kept "because Mohammadpur teaches it" or "because it is in the exam."

The drive runs **17 blocks across 15 weeks inside a 3-month cap** (§4). The heavy **tense cluster (Blocks 8–11) is protected at one full week each**; the compression that lets Blocks 1–16 fit inside 13 weeks comes only from **three shared weeks built on light/revision blocks and one safe contained pair** — never on the tense work. **Composition (Block 17) is the one deliberate exception to the compression logic**: principal ruling 2026-07-04 (v1.4→v1.5) gives it **two full weeks instead of one**, so paragraph and dialogue each get a dedicated week of practice rather than sharing a single week's four days. Vocabulary and grammar run **concurrently** (Class 4 holds a base from the C3 year + universal core).

Three things hold every block together, exactly as in the C3 pilot: practice **reuses words students already hold** (the POS-tagged pool, front-loaded); every block **ends in a self-construction (self-try) task** marked on the 4-point rubric (§9); and every block carries the **New Word Routine** (§8). All examples are authored in-house to Salafi/athari values in the school's house style — and the Class 4 papers are *already* Islam-aligned (prayers, Quran, Ramadan, du'ā, mosque), so the register is natural.

The load-bearing sections for building File 3 are **§2 (depth caps — how far each block teaches)** and **§4 (the block-by-week schedule)**.

- ☐ Practice is in the **format the school's paper tests** that structure (Rule 8; §7).

- ☐ All content **Salafi/athari, in-house, house style**; curation-at-source items excluded (Rule 6; §10).
- ☐ **Interjection examples (Block 13) are Islamic-register only** — SubhanAllah!/MashaAllah!/Alhamdulillah!/Inna lillah!; no Wow!/Yay!/Hurrah!/Oh!/Alas! (locked C3 Block 2 ruling against "hollow" exclamations).

## §1 — What this plan is

The Class 4 grammar track is **remedial and cumulative**: it works bottom-up along the spine, securing the lower rungs before the Class 4 rungs, and revisiting each earlier rung as later ones build on it. "Remedial" describes the bottom-up, gap-closing intent — not that any rung is revised before it has been taught. It is **book-bounded with a controlled, justified extension layer**. Every structure below is either (a) evidenced in the NCTB Class 4 book/TG, (b) a lower-class rung the cumulative spine re-teaches, or (c) a **selectively-kept addition** that passed all four of the Principal's gates — *fills a genuine gap · serves as a prerequisite · adds clear value · is manageable for Sylhet students.* Nothing is taught merely because the exam tests it.

**First-appearance teaching.** Every grammar concept receives its first explicit instruction, to its intended depth (§2 cap), at the point it first appears in the spine. No concept's initial teaching is deferred to a later revision or consolidation block; consolidation blocks revisit and secure concepts already taught. The re-walk step (Rule 2) is a bridge for students who already hold the lower rung, not the place a rung is first taught.

The 16 grammar blocks below are the approved Class 4 inventory. File 3 builds them **one block at a time, in spine order**, each as a self-contained teacher-facing file.

## §2 — The Class 4 grammar spine cut (rung-by-rung, with depth caps)

The **cap** is the guardrail: teach *to* the cap, never past it. "Re-walk" = a fast revision of the lower rung before the block's own work. **Disposition codes:** **[BOOK]** = book/TG grammar, taught in full · **[ADD]** = selectively-kept addition, depth-capped · **[REV]** = lower-class revision rung folded in at fast pace · **[REC]** = recognition-only exposure (no production, no graded item).

| # | Block | Teach to this depth (cap) | Do **not** go beyond (guardrail) |
|---|---|---|---|
| 1 | **Word & Word-Classes** [FIRST-TEACH] | A word has a meaning and a **job**; establish the **four core classes** as the working frame every later block re-uses (**noun, verb, adjective, adverb**). Spell → meaning (Bangla gloss allowed) → classify → use. | Build the frame from zero at discovery pace; no deep theory, no etymology. **Only the four core classes here**; Pronoun→B5, Preposition→B6, Conjunction/Interjection→B12. **Clue Card = 4 rows.** |
| 2 | **Noun** [BOOK]+[REV]+[ADD] | Common/proper; **number/plural** (-s/-es, -y→-ies, -f/-fe→-ves, pool irregulars); **countable/uncountable** + quantifiers (some/many/one) **[BOOK U8–U9]**. Fold: **gender — masc/fem/common/neuter** (pool pairs + lifeless-noun set) **[REV, graded]** and **collective nouns** **[ADD]** at ~5 high-frequency words. | Collective nouns: **team, class, family, flock, crowd only** — no memorisation lists. **Neuter is graded, not recognition-only** — HY26 Q9 tests lifeless nouns (*the moon*, *the mosque*); hold the same four-gender line C3 already set. No abstract/material-noun taxonomy. |
| 3 | **Sentence & Sentence Types** [ADD] | Name the five types — **assertive, interrogative, imperative, exclamatory, optative** — and identify which type a given sentence is. **Optative taught at full depth, not as the lightest type**: both binding papers test it directly (HY26 Q5(e), Annual Q5(e), *May Allah save you / grant you peace*), anchored to du'ā frames. Name-the-type + make one of each. | **Book-boundedness exception (documented):** the C4 textbook teaches no sentence-type content in any of its 18 units; this block is taught on binding exam evidence alone (HY26 Q5, Annual Q5 — both name all five types, one each, 5×1=5). No clause/phrase analysis. Sorrow-register exclamatory: teacher-given scenario only, never an open self-try prompt. |
| 4 | **Article** [BOOK]+[ADD] | **a/an/the** by **sound** (a university, a one-eyed, an hour, an honest, an M.P.) + **the** for specific/unique + **zero article (x)** for proper nouns/uncountables **[ADD, capped]**. Fill-in incl. "use x if none." | Teach a **fixed exception list**, not the full phonics rule. No abstract definiteness theory. (Known scope-creep trap — hold the line.) |
| 5 | **Adjective** [BOOK] | Describing words — *what kind/which/whose*; sit before the noun. Includes **my/his/her/our/their** (before a noun) and **this/that** before a noun. Identify in a passage; use to describe. | No comparative/superlative as a taught target. Do not relabel *my/his/this* as pronouns — before a noun they are adjectives (the C3 boundary, replicated). |
| 6 | **Pronoun** [BOOK] | Personal pronouns — subject (I/he/she/it/we/they) + object (me/him/her/us/them); they **replace** a noun. *this/that* light dual-use note. | No *mine/hers/ours/theirs* standalone forms; no relative/reflexive. *my/his/her/our/their* live in Block 5 (Adjective). |
| 7 | **Preposition** [BOOK] | Place/time prepositions the book uses (in, on, under, at, with, from, into, near, of, to). Identify (P.O.S.) + use. | No prepositional-verb/idiom work. |
| 8 | **Verb & Subject–Verb Agreement** [BOOK]+[ADD] | Simple present incl. **3rd-person -s/-es**; **SVA integrated and explicit** — *He goes (not He go) · is/are · each + singular* **[ADD — highest-value fix]**. Choose-correct-form. | SVA is **woven into the verb work, not a standalone block**. No deep agreement theory beyond the paper's choose-the-form items. |
| 9 | **Simple Past** [BOOK] | Regular -ed/-d + pool irregulars (is→was, go→went, give→gave, eat→ate…); structure subject + past-verb + rest. Fill-correct-tense. | No past perfect; no negative/question transforms beyond recognition. |
| 10 | **Continuous Tenses** [BOOK] | **Present continuous** (am/is/are + V-ing) **[U15]** + **past continuous** (was/were + V-ing) **[U18]**, taught **paired** so the be-verb shift is one idea. Fill-correct-tense. | No future continuous here (see Block 11). No deep aspect theory. |
| 11 | **Present Perfect** [BOOK] | have/has + past participle **[U11]**; "action that has happened recently." Recognise + use. **Worksheet volume trimmed** (not exam-weighted) — but taught in full as **book grammar and a Class 5 prerequisite**, to prevent a C5 gap. | Kept because it is Book/TG grammar + prerequisite, **not** dropped for low exam weight. No present-perfect-continuous. |
| 12 | **Simple Future** [ADD] + **Future Continuous** [REC] | **Simple future = will + base verb only** **[ADD — fills a real gap; book has no future]**. **Future continuous = recognition-only**: one teacher explanation + 3 examples (*I will be studying / They will be playing*) — pattern recognition so students don't panic on the exam. | Future: **no heavy tense charts.** Future continuous: **no production, no transformation, no worksheet, no graded item, no block of its own.** |
| 13 | **Parts of Speech (consolidation)** [REV]+[ADD] | The exam's "identify the P.O.S." integration point. Re-walk **adverb** + **conjunction** **[REV]**; add **interjection** **[ADD]** at **4 examples — SubhanAllah!, MashaAllah!, Alhamdulillah!, Inna lillah!** (Islamic register only, covering joy/praise/gratitude/sorrow — matches the C3 Block 2 exclamatory set; generic exclamations such as Alas!/Wow!/Hurrah!/Oh! are excluded under the locked C3 ruling against "hollow" interjections). Identify-the-bold-word across all eight classes. **Completes the 8-row Clue Card** — Conjunction + Interjection rows added here (Pronoun/Preposition rows were added at B5/B6). | Interjection: recognition, capped list, **Islamic register only — no secular exclamations**. Adverb/conjunction at revision pace (C3 rungs). No adverb-comparison/correlative theory. |
| 14 | **Sentence Types — recap** [REV] | **Recap only.** All five types receive their first explicit instruction at **Block 3**; this block revisits and secures them at revision pace ahead of the exam — re-name the five, re-identify across mixed examples, and re-touch the sorrow-register exclamatory (graded, *Inna lillah, how sad the news is!* pattern). | **Not first-teaching** — do not re-introduce the types as new (Block 3 owns first instruction, including optative at full depth). No clause/phrase analysis. Sorrow-register items: teacher-given scenario only (fill-in/identify) — never an open self-try prompt asking a child to produce their own sad sentence. |
| 15 | **Punctuation & Capitalization** [BOOK] | Capital at sentence start, proper nouns, **I**; full stop, question mark, exclamation mark; **comma in a list**; apostrophe. Rewrite a short passage correctly (ties exclamation/question marks back to Blocks 12–13). | Keep to what the papers test (HY Q3, Annual Q8); no semicolon/colon. |
| 16 | **Letters** [BOOK] | **Informal letter** (to a friend) **[U10]** + **formal letter/application** (to the Principal) **[U11, 7.4]**. The school tests both. Three-paragraph frame + address/date/salutation/closing. | Bounded to the paper's letter + application formats. Not free composition. |
| 17 | **Composition (applied)** [BOOK] | Short **paragraph** (≈6–8 sentences) on a familiar topic + **dialogue** with Islamic greetings + **sequence words** (First/Next/Then/After that/Finally) **[U13]**. The applied top of the track. **Now paced across two dedicated weeks (v1.5)** — paragraph gets a full week, dialogue gets a full week — for deeper practice reps; the depth cap itself is unchanged. | Not a creative-writing unit; bounded to the paper's paragraph + dialogue formats. Two weeks buys more repetition, not more scope. |

**Re-walk rule (Rule 2).** Each block opens by quickly re-touching the rungs below it, so a child who missed an earlier rung still has a footing.

## §4 — Block-by-week schedule (the 3-month fit)

**Feasibility verdict.** 17 blocks at one-per-week would exceed the cap on their own. Running **three shared weeks** compresses Blocks 1–16 into **13 weeks**, all placed so they **never compress the tense cluster**. The pairings: one **contained pair** (Adjective + Pronoun — both single-concept, heavy prior exposure); **Present Perfect (trimmed) + Simple Future (light)**; and the **two light revision blocks** (Parts of Speech + Sentence Types recap). Blocks 8, 9, 10 — the heaviest tense work for weak fundamentals — each keep a **full solo week**. **Sentence & Sentence Types (B3) runs as a new solo week at W3** (approved insert): it is first-teaching of content the C4 textbook does not carry at all, and both binding papers test it, so it cannot be paired or run at revision pace. **Punctuation (B15) and Letters (B16) each run as their own solo week** — B16 needs **4 full days** (2 informal letter, 2 formal application). **Composition (B17) owns two full weeks (W14–W15)** — paragraph gets a dedicated week, dialogue gets a dedicated week.

| **W2** | **B2 Noun** (+ gender·collective·count/uncount·number) | FULL | Fresh batch | Performance Test + Assignment |

**Why this shape.** Nouns/adjectives land early to feed Blocks 2, 4–5; verbs are all held before the tense cluster (W7–W10); the three shared weeks (W5, W10, W11) absorb the lights and one safe contained pair, so Blocks 1–16 fit inside 13 weeks **without touching W7/W8/W9**. **Sentence & Sentence Types (W3) is solo** — first-teaching of book-absent, exam-tested content. **Punctuation (W12) and Letters (W13) each run solo.** **Composition (W14–W15)** gets two full practice weeks; the graded Performance Test closes the block at the end of W15, with only a light spelling check at W14's close to keep the weekly rhythm intact. If a solo or paired week's Performance Test falls below the retention floor, the gate **holds and re-teaches** — which is the path by which the drive could slip beyond 15 weeks. That slippage is the intended safety behaviour, not a failure.

## §5 — Vocabulary reuse base (which words a block may use)

**Graded items** draw **only from words held by that week** — fresh batch to date + the C3-year base + the universal core. POS tags route each word to its matching block (nouns → Blocks 2, 4–5; verbs → Blocks 8–12; adjectives → Block 5; etc.). A student is never graded on a word not yet taught.

**Teaching examples** (worked examples, board illustration, teacher talk) **normally use held words**, but may use a **common, age-appropriate word not yet in the held set** where it makes a clearer or more natural example (Principal ruling). Any such word is still curation-screened (charter §H.9) and bound by the sacred-word guard (§H.3); it is used for illustration only, never as the answer in a graded item.

- **Front-load logic:** nouns/adjectives secured W1–W5 before the noun/article/adjective blocks; verbs secured before the tense cluster (W7–W10); Pronoun and Preposition reuse held nouns (as objects / place-words) and need little fresh vocabulary.
- **File 2 dependency:** the exact batch sizes and the per-block held-word lists lock when the **C4 vocabulary pool (File 2)** is built from the textbook. Until then, §4's "fresh batch" column is the *shape*, not the numbers.

## §6 — Bloom application (Class 4)

**Band (charter §G / REF-18 §4.1):** dominant **Understand, Apply**, with **more Analyze than Class 3** (sort, compare, find-the-error become routine) and **guided Create**. Class 4 sits one notch above the C3 pilot.

**Indicative block-scope mix (REF-18 §4.2):** Remember 15–25% · Understand 25–30% · Apply 25–35% · Analyze 15–25% · Evaluate 0–10% · Create 5–10%. Whole-block, not per-item.

**Climb within each block (Rule 5):** open at Remember/Understand (recognise + explain the rule), move to Apply (use it in the exam format), reach **Analyze** (sort/compare/error-find — the SVA "He go → He goes" correction lives here), close at **Create** (the self-try task). Run REF-18 §6 watch-outs before finalising any set — the *mental work* sets the level, not the verb.

**Paper-fidelity notes (for the block builds):**

- **Mark splits & wording** (e.g. 1×5, 2×5, 10, "Write only answers") are taken from the 2025–26 papers; reuse that phrasing in block practice.

## §8 — New Word Routine staging (Class 4)

**Rung (REF-18 / charter §N):** Class 4 = **Apply / Analyze** — `Meaning → Class → Use`, and **dual-job is now practised, not just introduced** (C3's note: dual-job fluency belongs to Classes 4–5). The clue card (naming→Noun; doing→Verb; describing→Adjective; how/when/where→Adverb) carries forward as a standing reference. **Block 1 builds the 4-row card (Noun/Verb/Adjective/Adverb); the remaining rows are added as each class is taught — Pronoun (B5), Preposition (B6), Conjunction + Interjection (B12).**

**Dual-job — practised at Class 4.** The harder adjective↔verb and adjective↔adverb dual-jobs that C3 deliberately held back (**hard, still, open, fast, clean**) are now active practice items, spread across the Noun, Verb, Adjective, and Parts-of-Speech blocks — a child names the word's job *in this sentence* and uses it both ways.

## §9 — Free-thinking close + marking rubric

Every block ends with a **self-construction (self-try) task** (charter §I): the student writes their own sentence/example using the block's rule **and** a word from the current set, after first **naming the word's class**. Frame it anchored, never open-ended (e.g. *"Write your own optative sentence as a du'ā using a word you learned this week"*).

**Rubric** = Charter §I.3 — **4 marks, four criteria at 1 mark each, uniform across all five classes**. Each criterion scores 1 or 0; no partial credit.
