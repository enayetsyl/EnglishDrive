# SCHOOL FOR COMMUNITY DEVELOPMENT
## Class 1 - English Grammar Campaign
### Block 05: Demonstrative — Clue Card (for the wall)

## This · That · These · Those — pointing words

They point at a naming word (noun) — like *book, tree, house.*

**কাছে (near) → this / these**  ·  **দূরে (far) → that / those**

**একটি (one) → this / that**  ·  **অনেক (many) → these / those**

| | one (একটি) | many (অনেক) |
|---|---|---|
| near (কাছে) | this | these |
| far (দূরে) | that | those |

## Our four sentences

| Frame | Example |
|---|---|
| This is a ___. | This is a book. |
| That is a ___. | That is a house. |
| These are ___. | These are pens. |
| Those are ___. | Those are trees. |

## How to read this chart

Ask two questions — **near or far?** and **one or many?** — then choose the word.

near + one = this · far + one = that · near + many = these · far + many = those.

*Optional teacher note:* Give the Bangla meaning aloud only when a child cannot follow the English. Show near/far with your hand, not with words on the sheet.
