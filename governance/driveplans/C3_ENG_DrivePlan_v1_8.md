## Summary (read this first — 60 seconds)

This is the Class 3 cut of the drive. Grammar runs as a **cumulative remedial track in spine order, bottom-up**, teaching **only the structures the Class 3 book actually uses**, openly and by name, because those structures are used in the Class 3 textbook and assessed in the school's examination papers. The drive starts **1 July**, runs **~12 grammar weeks** inside a **3-month cap**, and runs **vocabulary and grammar concurrently** — Class 3 already holds a base (Units 1–3, taught in class, plus the universal core), so the early grammar rungs have words to work with from day one while fresh weekly batches feed the heavier later blocks.

Three things hold every block together: practice **reuses words students already hold** (the POS-tagged pool, front-loaded so a block's words are secured before it is taught); every block **ends in a self-construction (self-try) task** marked on the rubric; and every block carries the **New Word Routine** — classify any word by its job, then use it. All examples are authored in-house to Salafi/athari values in the school's own house style (Islamic greetings, Suhoor/Maghrib/Quran, cleanliness and water themes, names like Nusair, Yusuf, Porshi).

The load-bearing sections for building File 3 are **§2 (depth caps — how far each block teaches)** and **§4 (the block-by-week schedule)**.

## §1 — What this plan is

The Class 3 grammar track is **remedial and cumulative**: it works bottom-up along the spine, securing the lower rungs before the Class 3 rungs, and revisiting each earlier rung as later ones build on it. "Remedial" describes the bottom-up, gap-closing intent — not that any rung is revised before it has been taught (see *First-appearance teaching*, below). It is **book-bounded** — every structure below is evidenced in the NCTB *English for Today* Class 3 text and/or tested in the binding Mohammadpur or Annual paper. No structure is taught simply because it "should" appear at Class 3; it is taught because the book uses it and the paper tests it.

The 14 grammar blocks below are the charter §E Class 3 inventory. File 3 builds them **one block at a time, in spine order**, each as a self-contained teacher-facing file.

**First-appearance teaching.** "Remedial and cumulative" means each rung is *taught, then revisited* — never *revisited before it is taught*. Every grammar concept receives its first explicit instruction, to its intended depth (§2 cap), at the point it first appears in the spine. No concept's initial teaching is deferred to a later revision or consolidation week; consolidation weeks revisit and secure concepts already taught. The re-walk step (Rule 2) is a bridge for students who already hold the lower rung, not the place a rung is first taught.

## §2 — The Class 3 grammar spine cut (rung-by-rung, with depth caps)

The **cap** is the guardrail: teach *to* the cap, never past it. "Re-walk" = a fast revision of the lower rung before the block's own work.

| # | Block | Teach to this depth (cap) | Do **not** go beyond (guardrail) |
|---|---|---|---|
| 1 | **Word** | A word is a unit with a meaning and a **job**. Spell it, give its meaning (Bangla gloss allowed), classify it by job (naming/doing/describing/how-when-where), use it in a sentence. | No word-class *theory* or terminology for its own sake; no etymology. |
| 2 | **Sentence & sentence types** | A sentence is a complete thought, starts with a capital, ends with a stop mark. Name the five types: **assertive, interrogative, imperative, exclamatory, optative**. Identify-and-name + make one of each. | No clause/phrase analysis; no subject–predicate labelling beyond "naming part / doing part" if a teacher needs it orally. |
| 3 | **Noun — common & proper** | Naming words; common vs proper; **proper nouns take a capital**. Identify-and-name in a sentence. | No abstract / collective / material-noun taxonomy (book does not test it). |
| 4 | **Noun — number (plural)** | Regular **-s / -es**, **-y → -ies**, **-f/-fe → -ves**, and the pool's irregulars (man→men, leaf→leaves, shelf→shelves, sheep→sheep, fish→fish), plural-only (clothes), uncountables (water, soap). | No countable/uncountable *rules* beyond "some words have no plural"; no Latin plurals. |
| 5 | **Noun — gender** | **All four genders — masculine / feminine / common / neuter.** Pick the noun, **write its gender (English term)**, in the paper's **find-and-classify** format (find the noun(s) in a sentence, write each gender). Built as **first formal gender instruction on no cross-year carry (PD-013)** — not assumed from Class 2. Graded on **held words + a declared 20-word block-local teaching set (PD-012)** that completes the four categories from the binding papers (taught in-block, gradeable in-block, not in File 2, not held downstream). The four category **terms are taught, not graded (PD-014)**. | Teach all four, but **no edge-case theory** on the common-vs-neuter boundary; keep to the paper's "find noun(s) + name each gender". **nephew–niece not adopted** (absent from all three C3 binding papers). |
| 6 | **Article (a / an / the)** | **a** before a consonant *sound*, **an** before a vowel *sound*, **the** for (i) the one already named, (ii) the one we mean / only one ("the Padma", "the sun"), **and (iii) a whole kind** ("the cow is a useful animal"). Fill-in. Generic *the* (iii) is **taught and produced**, on secular subjects only. | No zero-article rules; no abstract definiteness theory beyond the three named *the* uses. Graded items use held words **or the declared 14-word block-local set (PD-012)** completing the *an*-onset and sound-trap surface (*owl, ostrich, orange, egg, apple, umbrella, ant, olive, onion, elephant, ox, hour, honest, university*); block-local words are gradeable only inside this block and are never dictation/spelling items. Sacred-word guard (§H.3) applies: *Quran* may appear as a reverent subject, **never as a fill-in blank**; the HY2026 Q6 *Quran* item is prepared by **secular transfer** (same rule practised on *the cow / the ostrich*) and a marked teacher-script note, not by blanking the word. See §7 Article note. |
| 7 | **Adjective** | Describing words — *what kind / which / whose*; sit before the noun. **Includes my, his, her, our, their** (whose — the book's own usage) **and this / that when they come before a noun** (*this book, that boy* — which one). Identify in a passage; use to describe. Dual-job anchor **clean** (a clean hand / clean the school). | **No comparative/superlative as a taught item** — the book uses "faster than" communicatively but the paper does not test comparison. Do **not** relabel *my/his/this* as pronouns — before a noun they are adjectives. |
| 8 | **Pronoun** | **Personal pronouns** — subject (I, he, she, it, we, they) and object (me, him, her, us, them); they **replace a noun**. Fill-from-passage (Annual Q3). **Introduce this / that** in examples and sentences with a brief note that they can **point to a noun** (*this book* — taught in Block 7) **or stand in place of a noun** (*This is mine*); light touch, not a graded target. | Do **not** introduce *mine, hers, ours, theirs* (stand-alone forms — absent from the book and papers). *my, his, her, our, their* are taught in **Block 7** (before a noun), not here. No relative/reflexive/indefinite pronouns. |
| 9 | **Preposition** | Place and time prepositions the book uses (in, on, under, at, with, from, into, near, along, beside, of, **to**). Fill-from-passage. | No prepositional-verb/idiom work; no abstract use. |
| 10 | **Verb — present simple + basic present continuous** | Present simple incl. **3rd-person -s/-es** (he washes, she goes); subject–verb agreement; fill the right form (Annual Q4). **Plus basic present continuous** (*am/is/are* + V-**ing**: *I am reading, she is playing, they are running*) at **recognition-and-usage level only** — the book teaches it (defines "continuous tenses" and uses it) and **TG outcome 9.5.2** lists it. | **No deep tense analysis** — no past/future; no negative/question transforms; no simple-vs-continuous theory. Continuous is for recognition + simple use, **not** the Q4 form-fill (paper tests present simple only). |
| 11 | **Conjunction** | Joining words: **and, but, so, or, because**. Fill-from-passage. | No subordinate-clause analysis; no correlative pairs. |
| 12 | **Adverb** | The closed set the Annual tests — **always, carefully, quietly, happily, slowly** (+ pool: together, again, finally, sometimes, properly, regularly, everywhere); tells *how/when/how often*; sits with the verb. Fill-from-box / identify. | No comparison of adverbs; no adverb-of-degree theory. |
| 13 | **Punctuation & capitalisation** | Capital at sentence start, on proper nouns and **I**; full stop, question mark, exclamation mark; comma in a list; apostrophe in names/possessive; double quotation for reported speech. Rewrite correctly. | Keep to what the Annual Q9 tests; no semicolon/colon; double quotation for reported speech only (Annual Q9(d); textbook Unit 8 grounds it). |
| 14 | **Composition (applied)** | Short **paragraph** (≈5–7 sentences) on a familiar topic; **dialogue** with Islamic greetings. The applied top of the track. | Not a creative-writing unit; bounded to the paper's paragraph + dialogue formats. |

**Re-walk rule (Rule 2).** Each block opens by quickly re-touching the rungs below it (Block 5 re-touches "noun" before doing gender, etc.), so a child who missed the earlier rung still has a footing.

**Vocabulary prerequisites (Rule 3).** Each block requires certain *categories* of word to be teachable; File 2 supplies them and remains the single source of truth for what is held by any given week. Blocks 1–4 nouns and naming words · 5 masculine/feminine person nouns, common-gender nouns, neuter nouns · 6 consonant- and vowel-onset nouns · 7 adjectives and nouns to describe · 8 nouns as antecedents, subject and object pronouns · 9 place and time nouns · 10 verbs and their subjects · 11 joinable clause material · 12 manner and frequency adverbs · 13 proper nouns (names, months, days) · 14 the full held set. Where a block's week cannot supply a required category, that surfaces at build time against File 2, not here.

> **Note on the Block 7 / 8 boundary (v1.1).** The rule is positional: a word **before a noun** is an **adjective**; a word that **replaces a noun** is a **pronoun**. This matches the binding sources — the **book** labels only personal *you/me/it* as "Pronoun" and never labels *my/his/this*; the **TG** gives no grammar-category label for these words; the **Annual Q3** paper, though headed "Pronoun", tests personal pronouns only. Accordingly **my/his/her/our/their are taught in Block 7** (their before-a-noun usage) and **Block 8 keeps the personal pronouns**; **this/that** are introduced lightly in both blocks with the dual-use note. Stand-alone *mine/hers/ours/theirs* are not introduced. *(This boundary replicates to Classes 1/2/4/5; the same §2 rows carry down.)*

> **Note on Block 10 verb scope (v1.2).** Block 10 adds **basic present continuous** (*am/is/are* + V-ing) at recognition-and-usage level, because the **book** explicitly teaches it (it defines "continuous tenses" and uses 22 *am/is/are + V-ing* forms) and the **TG** lists it as outcome **9.5.2** — a block should not under-cover what the book and TG already introduce. It stays light: recognition and simple use, no tense analysis. The **Annual paper (Q4)** tests present-simple form only, so continuous is not graded in the exam format. ⚑ **Charter conflict:** charter §E inventory still reads "Verb — present simple form"; this plan now exceeds that cap. Since the charter overrides build inputs, §E needs a matching manual edit (e.g. "Verb — present simple + basic present continuous (recognition)") to keep the two consistent. *(Replicates to Classes 1/2/4/5 where the book/TG also introduce the continuous.)*

> **Note on Block 6 Article scope (v1.8).** The binding **HY2026 Q6** ("Fill in the blanks with suitable articles") tests a *the* use beyond "specific/unique": *"The cow is a useful animal"* and *"The Quran is a holy book"* both use **generic *the*** (the whole kind). A student cannot answer these without producing generic *the*, so Block 6 **teaches it as a named third *the* use and grades its production** — on **secular subjects only** (*the cow / the ox / the ostrich / the owl*). This widens the original "specific/unique" cap toward the binding paper (Principal ruling, 2026-07-26), on the same *map-then-decide* / paper-fidelity path used for Block 5 gender and Block 10 verb. **Sacred-word guard (§H.3) holds absolutely:** *Quran* is **never** a fill-in blank in any worksheet or Performance Test. The exam's *Quran* item is prepared by **secular transfer** — students meet the identical grammar on *the cow / the ostrich* and can therefore answer it — plus a marked teacher-script note permitting the teacher to read the exam sentence reverently in oral preparation. This is a **binding-paper vs Charter §H.3 tension** (the paper blanks an article on a sacred word, which the charter forbids us to author): resolved by teach-to-transfer, not by relaxing the guard. Held-vocabulary coverage of the *an*-onset surface is completed by a **declared 14-word block-local set (PD-012)**, gradeable only within the block, never dictation/spelling items. Bloom: whole-kind *the* is taught at Understand/Apply, not as abstract definiteness theory. Matches the built `C3_ENG_GrammarBlock06_Article_v1`. *(The generic-*the* widening and the sacred-word transfer method replicate to Classes 1/2/4/5 wherever the Article block meets the same paper items.)*

**Why front-loaded (the lead-time logic).** Nouns land W1–W3 to feed the noun and article blocks; adjectives are all held by W5 before the Adjective block (W6); verbs and adverbs are all held by W7 before the Verb (W9) and Adverb (W10) blocks. Pronoun and Preposition need no new words — they reuse nouns already held as objects and place-words. So fresh vocabulary finishes exactly as the grammar gets heavy. This is deliberate: W8–W12 teach their rungs for the first time on **fully-held vocabulary**, which is the intended support for first-teaching in the back half, not a signal that those weeks are revision.

**Weekly-load note (read before pacing).** Load per week is the sum of three things — grammar scope, fresh-vocabulary size, and the Performance Test. The peaks are not evenly spread:
- **W6–W7 — compound peak.** Heaviest grammar rungs (Adjective, Pronoun) coincide with the largest fresh batches (30 → 35 → 39) and a Performance Test. If retention softens here, hold the batch ramp rather than push it (the §3 retention gate is the intended relief valve — a hold is expected, not a failure), before the grammar load is compounded by new-word load.
- **W3 — double-rung peak, frozen.** Blocks 3–4 (common/proper **and** plural) sit in one week; plural is rule-heavy. W3 is within the frozen block range and is **not** rebalanced this revision (out of scope). Note only: do not schedule W4's heavier gender teach (four genders + English term) to compound against it — W4 is active scope and can be paced to give W3 room.
- **W4, W9 — heavier than the original plan implied.** W4 carries the widened four-gender teach (v1.4); W9 carries present simple **plus** basic present continuous (v1.2). Both are single-block weeks but denser than a bare block row suggests.
- **W10 — double-rung** (Conjunction + Adverb), no fresh vocab, so grammar-heavy but intake-light.

## §5 — Vocabulary reuse base (which words a block may use)

**Graded items** draw **only from words held by that week** — fresh batch to date + the already-taught Units 1–3 base + the universal core. POS tags in the pool route each word to its matching block. A student is never graded on a word not yet taught.

**Teaching examples** (worked examples, board illustration, teacher talk) **prefer held words**, but may use a **common, age-appropriate word not yet in the held set** where it makes a clearer or more natural example (Principal ruling). Any such word is still curation-screened (charter §H.9) and bound by the sacred-word guard (§H.3); it is used for illustration only, never as the answer in a graded item. This keeps grammar teaching from being distorted by vocabulary availability while preserving assessment fairness. *(Note: the vocabulary batch order remains coupled to grammar lead-time for graded items — a later Run Book revision to decouple it is deferred, so batch lead-time still applies to what may be graded each week.)*

- **Block 1 (Word, W1):** 20 fresh **nouns** (friend, morning, evening, time, school, home, family, football, fun, brother, mother, father, girl, member, card, house, year, banker, kite, thermometer) + the Units 1–3 base, which makes familiar **verbs** (see, meet, like, play) and **adjectives** (good, fine, nice, favourite) available for the classify-by-job step even though they are formally batched later. *Implication for the New Word Routine:* the all-noun fresh batch makes "naming word → Noun" the natural anchor; doing/describing words for classification come from the familiar base or as teacher-modelled examples.
- **Block 2 (Sentence types, W2):** W1 + W2 = 40 held nouns (incl. months January–June for proper-noun examples) + base. Enough to build assertive/interrogative/imperative/exclamatory/optative examples without new words.
- **Later blocks:** see §4 — the POS lead-time guarantees each block's matched words are held before it is taught.

## §6 — Bloom application (Class 3)

**Band (REF-18 §4.1):** dominant **Understand, Apply**; suitable exposure **simple Analyze, guided Create**. Begin "why / how / compare" on familiar content only.

**Indicative chapter-scope mix (REF-18 §4.2, Class 3–5):** Remember 20–30% · Understand 25–35% · Apply 25–35% · Analyze 10–20% · Evaluate 0–10% · Create 0–10%. These describe the **whole block**, not a single item.

**Climb within each block (Rule 5 / REF-18 ready-check):** open at Remember/Understand (recognise and explain the rule), move to Apply (use it on given items in the exam format), reach **simple Analyze** where the band allows (sort, compare, find-the-error), and close at **Create** (the self-try task). Run REF-18 §6 watch-outs before finalising any set — a high-level verb does not make a high-level item; the *mental work* sets the level.

**New Word Routine on the same logic:** Class 3 sits at **Apply** — classify a *novel* word (meaning → class → use) and the **introduction** of dual-job. Recognition/sorting rungs belong to Classes 1–2; dual-job fluency to Classes 4–5 (§8).

## §8 — New Word Routine staging (Class 3)

**Rung (REF-18 / charter §N):** Class 3 = **Apply** — `Meaning → Class → Use`. Classify by the **clue card** (naming→Noun; doing→Verb; describing-a-noun→Adjective; how/when/where→Adverb), then use the word in the current block's structure. A one-page clue card accompanies the File 3 set as a standing reference.

**Dual-job introduction — staged, gentle (charter §N).** Class 3 *introduces* dual-job ("a word's class comes from its job **here, in this sentence**"), it does not drill it heavily. The ~20-word dual-job set is spread across the **Noun, Verb, Adjective, Adverb** blocks (a few minimal-pair items each), leaning **noun↔verb** with **clean** as the single adjective↔verb anchor:

> water, plant, brush, drink, help, turn, start, cut, call, play, place, step, tap, exercise — + **clean** (adj↔verb). Harder adj/adverb dual-jobs (hard, still, open) are held for Classes 4–5.

**Where Blocks 1–2 sit:** Block 1 (Word) **introduces the routine and the clue card** on single-class words (the fresh batch is all nouns, so "naming word → Noun" anchors it), with at most one teacher-modelled dual-job taste — **not** a dual-job lesson. Block 2 (Sentence types) **uses** the routine inside sentence-building. The first real dual-job practice begins at the Noun and Verb blocks.

## §9 — Free-thinking close + marking rubric

Every block ends with a **self-construction (self-try) task** (charter §I): the student writes their own sentence/example using the block's rule **and** a word from the current set, after first **naming the word's class** (the classify-then-use step). Frame it anchored, never open-ended ("Write your own *optative* sentence as a du'ā using a word you learned this week" — not "write anything"). The self-try is a **graded item**: the student's own word must come from the **held set** for that week (held-vocabulary rule applies to graded items).

**Rubric** = Charter §I.3 — **4 marks, four criteria at 1 mark each, uniform across all five classes**. Islamic/value alignment is **not** a scored criterion (Charter §I.3, Run Book §13.1): §H binds all authored material in full, but a religiously neutral on-topic student answer earns full marks, and a §H conflict is flagged as a values matter rather than marked down. Each criterion scores 1 or 0; no partial credit.

| Criterion | Marks |
|---|---|
| Content accuracy (rule used correctly) | 1 |
| Reasoning (why it fits the rule / type) | 1 |
| Organisation | 1 |
| **Correct word-class placement** *(charter §N)* | 1 |
| **Total** | **4** |

*Scaling note:* for a single self-try **sentence** at Class 3, teachers read this rubric proportionally (a one-sentence answer is not marked like an essay) — the criteria are the point, not the raw total.

## §10 — Islamic alignment & house style

All content is **authored in-house** to Salafi/athari values (charter §H): tawhid-centred; no shirk/bid'ah-adjacent content; no other-faith festival/holiday content; no music/instruments (choral recitation, spoken repetition, du'ā/dhikr phrasing substitute for songs/rhymes); modest and akhlaq-positive throughout.

**House style — confirmed from the school's own papers** (mirror it in every block):
- **Islamic register is natural:** Islamic greetings, *Bismillah / SubhanAllah / Alhamdulillah*, Suhoor, Maghrib, Ramadan, fasting, salah, Quran, "obeying Allah" (Annual Q7, HY2026 Q9 both model this).
- **Names:** Nusair, Yusuf, Porshi, Raima, Rabab, Abdur Rahim, Jesmin Akter.
- **Themes:** cleanliness and hygiene, saving water, family and neighbours, helping one another, school and study, care for creation — matching the book's Units 6–8 and the papers.

**Curation already applied at source (do not reintroduce):** the five rhymes/songs (U2–U7) and the U8 hill-festival lesson are excluded; *singing/dancing* are set aside. Greetings and numbers are taught in their own lessons, not batched as memorisation words.
