## Doing Words — Verbs + am / is / are

*(কাজ-শব্দ = doing word · একজন কর্তা = one doer · অনেক কর্তা = many doers)*

**A doing word tells what someone does.** *(কাজ-শব্দ বোঝায় কেউ কী করে।)*
I **read**. · We **play**. · She **writes**. · They **look**.

| **নিয়ম (rule)** | **উদাহরণ (example)** |
| --- | --- |
| **এক কর্তা → কাজ-শব্দে -s** *(one doer → add **s**)* | the boy **reads** · she **looks** · Aisha **asks** |
| **অনেক কর্তা, বা I / we / you / they → কাজ-শব্দ একই** *(many, or I/we/you/they → plain)* | the boys **read** · we **look** · they **ask** |
| **এই -s আলাদা** *(this **s** is different)* | কাজ-শব্দের **s** = একজন কর্তা · নাম-শব্দের **s** = অনেক (book → book**s**) |

| **am / is / are** | **উদাহরণ (example)** |
| --- | --- |
| **আমি → am** *(I → am)* | I **am** at school. |
| **একজন → is** *(one → is)* | The bird **is** in the tree. |
| **অনেক, বা we / you / they → are** *(many → are)* | We **are** friends. |
