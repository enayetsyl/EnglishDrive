## Learning outcomes (plain form)

- Recognise that an adjective is a describing word that describes a naming word (noun).
- Read and spell the ten taught adjectives (five pairs): tall/long · soft/hard · clean/dirty · sweet/sour · weak/strong.
- Choose the correct adjective from two options in a description sentence.
- Underline the adjective in a sentence.
- Write one describing-word sentence of their own (guided self-try).

---

## Clue Card content (build with the class Sun–Tue; on the wall by Thursday)

> **An adjective is a describing word.**
> It describes a naming word (noun) — like *boy, bird, mango.*
>
> **Noun কে বর্ণনা করে। জিজ্ঞেস করে — এটি কেমন?**
>
> **Our describing words:** tall · long · soft · hard · clean · dirty · sweet · sour · weak · strong

| Adjective | Example |
|---|---|
| tall ↔ long | a tall boy · a long road |
| soft ↔ hard | a soft bed · a hard stone |
| clean ↔ dirty | a clean hand · a dirty bag |
| sweet ↔ sour | a sweet mango · a sour lemon |
| weak ↔ strong | a weak cat · a strong lion |

*How to read the chart:* read the English word first, then the picture in the mind, then the meaning. A describing word comes before a naming word: a soft bird, a strong cow.

*Optional teacher note:* Give the Bangla meaning aloud only when a child cannot follow the English word. The Bangla on the chart is a support — let the child read the English first, or they will lean on the Bangla and stop reading the English.

# Sunday — the term *adjective* · pairs 1–2 (tall/long, soft/hard)

**Vocabulary today:** the term *adjective*; tall, long, soft, hard (first exposure — read and spell).

| Step | Time | Focus |
|---|---|---|
| 1 | 0–5 | Track A oral routine (never cut) |
| 2 | 5–8 | Re-walk: what is a naming word? |
| 3 | 8–14 | The term: adjective (say · break · read · spell) |
| 4 | 14–18 | Teach pair 1 — tall / long |
| 5 | 18–23 | Teach pair 2 — soft / hard |
| 6 | 23–33 | CW-1 — in the notebook (~10 min) |
| 7 | 33–35 | Exit Check |

**Step 1 — Track A oral routine (0–5):** standing routine — alphabet spot-check · numbers 1–10 · greeting · command drill · one Q&A pattern. Never shortened for grammar.

**Step 2 — Re-walk naming words (5–8):** Books closed. Write: boy · bird · mango · book · tree. "What do we call these words?" → Naming words. Nouns. "A naming word names a person, an animal, a place, or a thing." "Today we learn a new kind of word — one that describes a naming word."

**Step 3 — The term: adjective (8–14):** "a tall boy, a soft bed, a sweet mango — the words tall, soft, sweet describe the naming word. They are called adjectives." Board-write **adjective**; show ad · jec · tive; read part by part, then whole word ×3. Spell aloud a–d–j–e–c–t–i–v–e; class copies once. Post the Clue Card, read the top line together. First exposure — say/read/spell; recall checked from Monday.

**Step 4 — tall / long (14–18):** Word-cards, meaning → read → spell → use. **tall** — "a tall boy is high" (reads ×3; spell t-a-l-l). **long** — "a long road goes far" (reads ×3; spell l-o-n-g). "Which word for the boy who stands high?" → tall. "For the road that goes far?" → long. *(In Bangla both are লম্বা — English has two words; teach that. Oral only if stuck.)* Clue Card row 1.

**Step 5 — soft / hard (18–23):** **soft** — "a pillow is soft" (reads ×3; spell s-o-f-t). **hard** — "a stone is hard" (reads ×3; spell h-a-r-d). "Which for the bed?" → soft. "For the stone?" → hard. Clue Card row 2.

**Step 6 — CW-1 in the notebook (23–33):** No worksheet. Write the four items on the board (or read aloud); children answer in the khata. Model item 1: read the sentence, read both choices, circle/write the fit. *"My father is a tall man — tall or long? A man stands up high — tall."*
> **CW-1 notebook items (teacher answers in brackets):**
> 1. My father is a (tall / long) man. → tall
> 2. The tree is very (tall / soft). → tall
> 3. A pillow is (soft / hard). → soft
> 4. The stone is (hard / long). → hard

**Step 7 — Exit Check (33–35):** One prompt per student (roll = 7); teacher says a describing word, student reads it and uses it in "a ___ ___". Prompts: tall / soft / long / hard / tall / soft / hard. Answer alone suffices.

# Monday — pairs 3–4 (clean/dirty, sweet/sour) + revise Sunday

**Vocabulary today:** recall term *adjective*; clean, dirty, sweet, sour (read and spell); revise tall/long/soft/hard.

| Step | Time | Focus |
|---|---|---|
| 1 | 0–5 | Track A oral routine |
| 2 | 5–9 | Recall Sunday + term recall |
| 3 | 9–15 | Teach pair 3 — clean / dirty |
| 4 | 15–21 | Teach pair 4 — sweet / sour |
| 5 | 21–25 | Quick mixed oral (4 pairs) |
| 6 | 25–33 | CW-2 — done in class (~8 min) |
| 7 | 33–35 | Exit Check |

**Step 2 (5–9):** Books closed. "What is the new word for a describing word?" → Adjective (say ×2; a child or two spell aloud). Rapid oral: teacher says noun + gesture, class supplies tall/long/soft/hard.

**Step 3 — clean / dirty (9–15):** **clean** — "a washed hand is clean" (reads ×3; c-l-e-a-n). **dirty** — "my shoes are dirty" (reads ×3; d-i-r-t-y). "Which for the washed hand?" → clean. Clue Card row 3.

**Step 4 — sweet / sour (15–21):** **sweet** — "a ripe mango is sweet" (reads ×3; s-w-e-e-t). **sour** — "a lemon is sour" (reads ×3; s-o-u-r). "Which for the lemon?" → sour. Clue Card row 4.

**Step 5 — mixed oral (21–25):** Shuffled word-cards, all four pairs. Show → class reads → one child uses it in "a ___ ___". Fast and light.

**Step 6 — CW-2 in class (25–33):** Distribute CW-2 (Sun + Mon words). Model item 1. Students complete in class (~8 min). HW-2 goes home separate.

**Step 7 — Exit Check (33–35):** roll = 7; reads a taught word and uses it, drawn from all four pairs. Prompts: clean / sour / sweet / dirty / clean / sweet / sour.

# Tuesday — final pair (weak/strong) + all-five revision + begin guided choose

**Vocabulary today:** weak, strong (read and spell); revise all previous eight; begin guided exercises using taught words only.

| Step | Time | Focus |
|---|---|---|
| 1 | 0–5 | Track A oral routine |
| 2 | 5–10 | Revise all eight taught words |
| 3 | 10–18 | Teach pair 5 — weak / strong |
| 4 | 18–30 | CW-3 — done in class, slowly (read and decide) |
| 5 | 30–35 | Exit Check |

**Step 2 (5–10):** Shuffled word-cards, pairs 1–4. Read the card, give a noun it describes. Recall the term *adjective* once.

**Step 3 — weak / strong (10–18):** The hardest pair — taught last, most revision behind it. **strong** — flex arm, "a lion is strong" (reads ×3; s-t-r-o-n-g, note the *str* start). **weak** — "a sick cat is weak" (reads ×3; w-e-a-k, note *ea*). "Which for the lion?" → strong. Clue Card row 5. All five pairs now on the wall.

**Step 4 — CW-3 in class (18–30):** Distribute CW-3 (all five pairs) — the week's fullest sheet; give the full twelve minutes, let them work slowly. Children read each sentence, read both choices, decide on their own. Teacher moves around and guides (re-read, point to Clue Card, "which one fits?") but does not give the answer. Model item 1 aloud first. HW-3 goes home separate.

**Step 5 — Exit Check (30–35):** roll = 7; a choose-pair spoken aloud, child picks and says why in a word/short phrase (English or Bangla). Prompts: lion → strong · sick cat → weak · elephant → strong · tired frog → weak · cow → strong · sick boy → weak · horse → strong.

# Wednesday — consolidation: recognition + underline + ungraded self-try rehearsal

**No new vocabulary.** Cumulative practice, a new task shape (underline the adjective), the self-try rehearsal (not graded).

| Step | Time | Focus |
|---|---|---|
| 1 | 0–5 | Track A oral routine |
| 2 | 5–12 | Revise all ten; introduce *underline the adjective* |
| 3 | 12–24 | CW-4 — choose + underline practice |
| 4 | 24–31 | Self-try rehearsal (ungraded) |
| 5 | 31–33 | Set up Thursday PT |
| 6 | 33–35 | Exit Check |

**Step 2 (5–12):** Fast oral round, all ten words. Then teach the recognition move: "In 'The tall boy reads a book', which word describes the boy?" → tall. "We underline it." Model 2–3 on the board.

**Step 3 — CW-4 in class (12–24):** Distribute CW-4 (underline; all taught words). Students complete in class (~12 min). HW-4 goes home separate.

**Step 4 — Self-try rehearsal (24–31) — ungraded:** "Now you try on your own. I will not help. Write one sentence. Use one describing word you learned and a naming word you know." Board frame: **___ is a ___ [adjective] ___.** (e.g. My brother is a tall boy.) Silent writing ~4 min; 2–3 volunteers read aloud; feedback on **accuracy only — no marks**. Thursday's graded self-try uses different prompts. *(Sacred-word guard, attribution screen, non-mahram screen apply to anything shared or displayed.)*

**Step 5 — Set up Thursday PT (31–33):** Tell the class: Thursday has spelling, meanings, months, letter-words — and one describing-word sentence of your own.

**Step 6 — Exit Check (33–35):** roll = 7; read a short sentence aloud, child names the adjective (prompts differ from the worksheets): "The tall boy runs" → tall · "My clean hands" → clean · "The strong cow" → strong · "A sour lemon" → sour · "The soft bird" → soft · "A long road" → long · "The weak frog" → weak.
