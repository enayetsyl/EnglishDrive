### ধাপ ২ — Noun + plural re-walk (৫–১০ মিনিট)

**করণীয়:** বোর্ডে লিখুন: *cat · book*। দ্রুত প্রশ্ন-উত্তর — উত্তর বলে দেবেন না।

| শিক্ষক বলবেন | প্রত্যাশিত উত্তর |
|---|---|
| "Cat — এটি কোন ভূমিকা (role) পালন করছে?" | Noun — একটি প্রাণীর নাম |
| "Book?" | Noun — একটি জিনিসের নাম |
| "Noun মানে?" | মানুষ, প্রাণী, জিনিস বা স্থানের নাম |
| "one cat → অনেক হলে?" | cats (শেষে –s) |
| "one book → দুটো হলে?" | books |

**শিক্ষক বলবেন (সংযোগ):** "ঠিক। Noun কী ও plural কীভাবে বানাই — জানি। আজ Noun নিয়ে একটি নতুন কথা — প্রতিটি Noun-এর একটি **gender** আছে। gender মানে: নামটি পুরুষের নাকি নারীর।"

---

### ধাপ ৩ — masculine ও feminine পরিচয়: ৩টি জোড়া teacher-model (১০–২০ মিনিট)

**করণীয়:** বোর্ডে দুই-কলাম table আঁকুন: **masculine (পুরুষবাচক) | feminine (স্ত্রীবাচক)**। নিচের ৩টি জোড়া একে একে model করুন; শিক্ষার্থীরা repeat করে।

**শিক্ষক বলবেন (model — ১ম জোড়া):** "দেখো — *father* মানে বাবা। বাবা পুরুষ। তাই *father* is **masculine**।" (বোর্ডে father লিখুন masculine কলামে।) "*mother* মানে মা। মা নারী। তাই *mother* is **feminine**।" (বোর্ডে mother লিখুন feminine কলামে।)

| বোর্ডে যোগ করুন | শিক্ষক বলবেন | শিক্ষার্থীরা বলবে |
|---|---|---|
| father \| mother | "father — masculine। mother — feminine। সবাই বলো।" | "father — masculine। mother — feminine।" |
| brother \| sister | "brother — masculine। sister — feminine।" | repeat |
| son \| daughter | "son মানে পুত্র — masculine। daughter মানে কন্যা — feminine।" | repeat |

**বোর্ড এখন:**

| masculine | feminine |
|---|---|
| father | mother |
| brother | sister |
| son | daughter |

**করণীয় (নিয়ম বলুন):** "পুরুষ মানুষের নাম **masculine** — father, brother, son। নারী মানুষের নাম **feminine** — mother, sister, daughter।"

> **শিক্ষক নোট:** son ও daughter এখনো vocabulary pool-এ নেই। এখন শুধু দেখিয়ে দেন — S2-এ abbreviated NWR-এ formally introduce হবে।

### ধাপ ৪ — Abbreviated NWR: boy · girl · man · woman · uncle · aunt (২০–৩৫ মিনিট)

**পদ্ধতি:** See → Hear → Say → Mean (Frame নেই — gender table-ই frame)। প্রতিটি শব্দ board-এ লিখুন, পড়ুন, শিক্ষার্থীরা repeat করুন, Bengali meaning বলুন। জোড়াজোড়া দেখান এবং সঙ্গে সঙ্গে masculine/feminine কলামে যোগ করুন।

| Board-এ লিখুন | শিক্ষক করবেন | শিক্ষার্থীরা করবে |
|---|---|---|
| **boy** | "Boy — পড়ো।" (Hear) | "boy" (Say) |
| | "boy মানে ছেলে।" (Mean) | "boy মানে ছেলে" |
| **girl** | "Girl — পড়ো।" | "girl" |
| | "girl মানে মেয়ে।" | "girl মানে মেয়ে" |
| | "boy **masculine** — girl **feminine**।" (কলামে যোগ করুন) | "boy masculine, girl feminine" |
| **man** | "Man — পড়ো।" | "man" |
| | "man মানে পুরুষ মানুষ।" | repeat |
| **woman** | "Woman — পড়ো।" | "woman" |
| | "woman মানে নারী মানুষ।" | repeat |
| | "man **masculine** — woman **feminine**।" (কলামে যোগ করুন) | repeat |
| **uncle** | "Uncle — পড়ো।" | "uncle" |
| | "uncle মানে চাচা।" | repeat |
| **aunt** | "Aunt — পড়ো।" | "aunt" |
| | "aunt মানে চাচী।" | repeat |
| | "uncle **masculine** — aunt **feminine**।" (কলামে যোগ করুন) | repeat |

**বোর্ড এখন (S1 সম্পূর্ণ):**

| masculine | feminine |
|---|---|
| father | mother |
| brother | sister |
| son | daughter |
| boy | girl |
| man | woman |
| uncle | aunt |

**করণীয় (দ্রুত oral drill — board দেখে):** feminine column ঢেকে দিন। masculine word দেখিয়ে জিজ্ঞেস করুন: "mother-এর masculine?" → father। "sister?" → brother। ২–৩টি করুন, তারপর ছেড়ে দিন।

> S1 শেষে বোর্ড মুছবেন না — S2-এ দরকার হবে।

**হোমওয়ার্ক S1:** নেই।
