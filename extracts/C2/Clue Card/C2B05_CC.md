## Singular / Plural

*(একবচন = one · বহুবচন = more than one)*

| নিয়ম | উদাহরণ (ধরা শব্দ) |
|---|---|
| বেশির ভাগে শেষে **-s** | book → book**s** · bird → bird**s** · boy → boy**s** |
| **-es** (s/sh/ch/x-এ শেষ) | glass → glass**es** · box → box**es** · watch → watch**es** |
| **y → -ies** (y-এর আগে a, e, i, o, u **নয়**) | family → famil**ies** · city → cit**ies** · **কিন্তু** day → days *(y-এর আগে a, e, i, o, u থাকলে শুধু -s)* |
| **পুরো বদলে যায়** *(irregular — চেনানো)* | tooth → teeth · child → children |
| **একই থাকে** *(no change)* | sheep → sheep |
