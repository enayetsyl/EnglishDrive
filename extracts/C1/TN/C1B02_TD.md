# Class 1 English — Teacher Delivery Sheet
## Block 02: Noun — Number (Plural –s) (W2 · ১২–১৬ জুলাই ২০২৬ · ৫টি period, রবি–বৃহস্পতি)

> **এই শিটটি কী:** শুধু ক্লাসে পড়ানোর জন্য — teaching script, board work, delivery sequence, target উদাহরণ, PT পরিচালনা-নির্দেশ ও self-try রুব্রিক। উত্তর-চাবি, dictation শব্দ-তালিকা ও build-নোট এতে নেই (master ফাইলে)।

**Delivery language:** Bangla-led (English grammar terms + target words English-এ)।
**সময়সূচি:** S1–S4 teaching (রবি–বুধ, ৩৫ মি.) + S5 বৃহস্পতি Performance Test।

> **পরিভাষা নোট:** "Plural" = **বহুবচন** (একটির বেশি)। "Singular" = **একবচন** (একটি মাত্র)। Class 1-এ কেবল এই দুটি সরল term।

> **⚑ গভীরতা-সীমা:** এই ব্লকে **কেবল regular –s** শেখানো ও graded (*one cat → two cats*)। **–es / –ies / –ves কখনও শেখানো বা graded নয়।** Irregular (mice/children) শুধু **মৌখিক gloss** — "special word, পরে শিখব"। **fish → fish** — শুধু বানান ও অর্থ; plural drill-এ কখনও নয়।

## Learning outcomes (plain form)

- Singular ও Plural চেনা; নিয়ম বলা: **একটির বেশি → noun-এর শেষে –s**।
- Choose-and-rewrite ও singular/plural table পূরণ করা (regular –s)।
- W2-এর ১০টি শব্দ: duck · frog · lion · fish · parrot · book · pen · pencil · bag · tree।
- April · May · June — বলা ও বানান করা।
- নিজে একটি plural বাক্য তৈরি (self-try)।

**Bloom shape (§G.3 climb):** Remember (S1) → Understand (S2) → simple Apply (S3) → simple Create (self-try, S4)। নিচু থেকে শুরু, ধাপে ধাপে ওঠে।

## Singular / Plural wall card (দেয়ালে টাঙান)

| Singular (একটি) | → নিয়ম → | Plural (একটির বেশি) |
|---|---|---|
| one cat | **শেষে –s যোগ করো** | two cats |
| one book | **শেষে –s যোগ করো** | two books |
| one tree | **শেষে –s যোগ করো** | two trees |

> **নিয়ম:** একটি হলে → noun যেমন আছে তেমন। একটির বেশি হলে → noun-এর **শেষে –s**।
> **⚠ special শব্দ:** *fish → fish* (বদলায় না)। *mice, children* — "special, পরে শিখব"। drill-এ নেই।

# সেশন S1 — রবিবার ১২ জুলাই (New teaching)

**উপকরণ:** বোর্ড; ১২-মাসের চার্ট (April·May·June); Singular/Plural wall card; শব্দকার্ড: duck · frog · lion · fish · parrot।

**ধাপ ১ — Track A (০–৫ মিনিট):** ৬-ধাপ। ধাপ ৬-এ April · May · June।

**ধাপ ২ — Noun re-walk (৫–১০ মিনিট):** বোর্ডে *cat · book · Aisha · Sylhet।* দ্রুত প্রশ্ন — উত্তর বলে দেবেন না।

| শিক্ষক বলবেন | প্রত্যাশিত উত্তর |
|---|---|
| "Cat কী — প্রাণীর নাম নাকি কাজের নাম?" | প্রাণীর **নাম** |
| "Book কী?" | জিনিসের নাম |
| "Aisha কী?" | মানুষের নাম |
| "Sylhet কী?" | স্থানের নাম |
| "এই চারটির মিল?" | সবই কোনো কিছুর **নাম** |
| "মানুষ, প্রাণী, জিনিস, স্থানের নামকে কী বলে?" | **Noun (বিশেষ্য)** |

**শিক্ষক বলবেন:** "ঠিক। এগুলো সবই **Noun**। আজ দেখব — একটির বেশি হলে noun কীভাবে বদলায়।"

**ধাপ ৩ — Plural concept: Remember (১০–২৩ মিনিট):** বোর্ডে দুটো কলাম। ৫টি pair মডেল করুন, তারপর ৭ জনকে oral drill।

**Model:** "দেখো — cat। একটি — **one cat**। দুটো? শেষে **–s** যোগ করি — **two cats**।"

| Singular | Plural |
|---|---|
| one cat | two cats |
| one bird | two birds |
| one book | two books |
| one pen | two pens |
| one tree | two trees |

**Oral drill — ৭ জনকে আলাদা:**

| শিক্ষক বলবেন | প্রত্যাশিত উত্তর |
|---|---|
| "সবাই: one cat, two ___" | cats |
| "[Nusair], one bird, two ___?" | birds |
| "[Aisha], one book, three ___?" | books |
| "[Yusuf], one pen, two ___?" | pens |
| "[Raima], one tree, four ___?" | trees |
| "[Abdullah], one cat, many ___?" | cats |
| "[Porshi], one bird, five ___?" | birds |

**নিয়ম সংক্ষেপ:** "একটির বেশি → noun-এর শেষে –s। এটাই **Plural (বহুবচন)**।"

*irregular gloss (graded নয়): "mice, children special word, পরে শিখব।"*

**ধাপ ৪ — New Word Routine: duck · frog · lion · fish · parrot (২৩–৩৫ মিনিট):** প্রতিটি See → Hear → Say → Mean → Frame (~২.৫ মি.)। ৭ জনকে পর্যায়ক্রমে।

> **⚠ fish — guard নোট (একবারেই):** fish-এর plural **fish**। fish **কখনও** plural drill/CW/PW/HW/PT-এর plural আইটেমে নয় — শুধু **বানান ও অর্থ**।

| শব্দ | অর্থ | Frame → শিক্ষার্থী পূরণ |
|---|---|---|
| **duck** | হাঁস | "This is a duck." → "A duck is a ___." (animal) |
| **frog** | ব্যাঙ | "This is a frog." → "A frog is a ___." (animal) |
| **lion** | সিংহ | "A lion is a big animal." → "A lion is a ___ animal." (big/strong) |
| **fish** ⚠ | মাছ | "This is a fish." → "A fish is a ___." (animal) — *plural drill-এ নয়* |
| **parrot** | টিয়া | "A parrot is a bird." → "I see a ___." |

**হোমওয়ার্ক S1:** নেই।

# সেশন S2 — সোমবার ১৩ জুলাই (Guided practice)

**উপকরণ:** বোর্ড; wall card; শব্দকার্ড: book · pen · pencil · bag · tree।

**ধাপ ১ — Track A (০–৫ মিনিট):** ধাপ ৫-এ S1 শব্দকার্ড থেকে ২–৩টি।

**ধাপ ২ — Plural review + "কেন?" (৫–১০ মিনিট):**

| শিক্ষক বলবেন | প্রত্যাশিত উত্তর |

| "[Porshi], one cat → many?" | cats |
| "[Abdullah], one duck → two?" | ducks |
| "[Abdur Rahim], one parrot → three?" | parrots |

| "নিয়মটি বলো — সবাই।" | একটির বেশি → শেষে –s |

**ধাপ ৩ — New Word Routine: book · pen · pencil · bag · tree (১০–২০ মিনিট):**

| শব্দ | অর্থ | Frame → শিক্ষার্থী পূরণ |
|---|---|---|
| **book** | বই | "This is a book." → "I have a ___." |
| **pen** | কলম | "This is a pen." → "I write with a ___." |
| **pencil** | পেন্সিল | "This is a pencil." → "I have a ___." |
| **bag** | ব্যাগ | "This is a bag." → "My ___ is on the chair." |
| **tree** | গাছ | "This is a tree." → "A tree is ___." (big / a plant) |

**ধাপ ৪ — Guided plural practice: Understand → Apply (২০–৩৫ মিনিট):**

**অংশ ক — Choose correct form (guided, oral) (২০–২৮ মিনিট):** প্রথমটি একসাথে; বাকিগুলো পর্যায়ক্রমে।

| বাক্য (বোর্ডে) | সঠিক | কেন |
|---|---|---|
| Nusair has one (bag / bags). | **bag** | one → –s নয় |
| I see two (bird / birds) in the tree. | **birds** | two → –s |
| There are three (book / books) on the desk. | **books** | three → –s |
| Aisha has one (cat / cats). | **cat** | one → –s নয় |
| We see five (tree / trees). | **trees** | five → –s |

**Model:** "'one bag' — এক মানে একটি, তাই –s নেই। উত্তর: bag।"

**অংশ খ — Guided fill-in table (২৮–৩৫ মিনিট):** শিক্ষক প্রথম দুটো মডেল করে দেখান; বাকিগুলো শিক্ষার্থীরা বলে (dog→dogs, frog→frogs, parrot→parrots, cow→cows, lion→lions, book→books)।

**হোমওয়ার্ক S2:** নেই।

# সেশন S5 — বৃহস্পতিবার ১৬ জুলাই (Performance Test + weighted revision)

**উপকরণ:** test sheet; HW সংগ্রহ। **কোনো নতুন grammar নয়।**

**ধাপ ১ — Track A (সংক্ষিপ্ত, ০–২ মিনিট):** Greeting + মাস (April · May · June)।

**ধাপ ২ — Test preview (২–৫ মিনিট):** বোর্ডে **parrot · bag · tree**। See → Hear → Say → Mean (Frame নয়)।

**ধাপ ৩ — Performance Test (৫–৩৫ মিনিট):** test sheet বিতরণ (student-facing extract আলাদা)। **Part A (Spelling) আপনি পড়বেন — প্রতিটি শব্দ দুইবার, ধীরে।**

**Performance Test procedure (student-facing):**
- **Part A — Spelling [৫]** (শিক্ষক পড়বেন) · **Part B — Bengali Meaning [৫]** · **Part C — 12 Months [৩]** · **Part D — Letter-Words [২]** → vocabulary মোট **১৫**।
- **Part E — Embedded Drills [৬]** (E1 Preposition 3 · E2 Article 2 · E3 Noun ID 1) — **আলাদা ট্র্যাক**, retention gate-এ নয়।

> **⚑ Embedded revision — diagnostic-weighted (W1, ৭ জন):** দুর্বল টপিক teaching-touch + বেশি test-আইটেম দুই-ই পায়। **Preposition** সবচেয়ে ভারী (E1, ৩ আইটেম + S3/S4 micro-revisit); **Article** মাঝারি (E2, ২); **Noun ID** সবচেয়ে হালকা (E3, ১)। describing/adjective এই সপ্তাহে graded নয় (W4 টপিক)।

> dictation শব্দ-তালিকা ও Part C/D নির্দিষ্ট উত্তর master (teacher copy)-তে; এই শিটে ছাপা নেই।

**ধাপ ৪ — মূল্যায়ন ও retention gate (পরের সেশনের আগে):**

Retention gate (Part A + B + C = ১৩ নম্বর থেকে):

| শ্রেণির গড় | পদক্ষেপ |
|---|---|
