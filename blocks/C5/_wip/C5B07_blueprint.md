## 2 · The block's design spine — the boundary

**Before a noun → Adjective. Standing alone → Pronoun.** The same surface word takes both jobs (*her*, *this*, *that*), and **position decides**.

This is **not** a §N dual-job pair (§N.4 defines those as primarily noun↔verb) — it is the boundary §2 Blocks 7a/7b mandate directly. **The §N dual-job engine and 3–4-class fluency work stay at Block 9, unspent** (Drive Plan §8).

**One-defensible-answer discipline (absolute):** *my/his/her/our/their/this/that* graded **Adjective only when a noun follows**; personal pronouns graded **only standing alone**. Ambiguous bare *her* appears in taught contrast only, **never in a graded slot**.

## 3 · Label set and the staging guard

Gradeable labels: **Noun · Verb · Adjective · Adverb · Pronoun** — five.

**Barred:** Preposition (Block 8), Conjunction (Block 13), Interjection (Block 9). A rule not yet taught must not appear as an answer option (Spec Phase 4). Block 7 is a **staged instalment of the Block 9 exam format**; Block 9 widens it to eight.

**The C5 depth increase over C4B05** is the **adverb distractor**: C4 held no adverbs and ran four labels. C5 holds 8 adverbs from W2 and taught Adverb in B01, so the held pool supplies real minimal pairs — ***quiet/quietly · careful/carefully***. Harder discrimination, same format, no cap widening, no new vocabulary.

### Staging table (audit against this — Spec Phase 4)

|---|---|---|
| 1 Sun | *what kind · which · how many* adjectives | Noun · Verb · Adjective · Adverb |

**Pronoun must not appear as an option on any Day 1–2 sheet.** This is the exact defect `C4B05` v1.11 had to correct.
