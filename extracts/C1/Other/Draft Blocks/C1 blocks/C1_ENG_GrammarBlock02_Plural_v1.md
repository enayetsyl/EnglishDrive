# Class 1 English Drive — Grammar Block 2: **Noun — Number (Plural –s)** (teacher-scripted week plan)

**File 3, Block 2 of 10** · built against `C1_ENG_DrivePlan_v1.md` · audience: classroom teacher · delivery language: **Bangla** (English grammar terms + target words kept in English) · version: v1

> **এই ফাইল কীভাবে ব্যবহার করবেন:** প্রতিটি সেশন ধাপে ধাপে সাজানো। **করণীয়** = আপনি কী করবেন; **শিক্ষক বলবেন / প্রত্যাশিত উত্তর** টেবিল = হুবহু বলার কথা ও ছাত্রছাত্রীরা কী বলবে। লাইন ধরে ধরে চালালেই সেশন হয়ে যাবে। CW ও HW worksheet এই ফাইলে এম্বেড করা আছে — S3-এ প্রিন্ট করুন বা বোর্ডে লিখুন।

> **পরিভাষা নোট:** "Plural" মানে **বহুবচন** (একটির বেশি)। "Singular" মানে **একবচন** (একটি মাত্র)। এই দুটো grammar term শিক্ষার্থীদের মনে রাখতে হবে।

### ধাপ ২ — Noun re-walk (৫–১০ মিনিট)

**করণীয়:** বোর্ডে লিখুন: *cat · book · Aisha · Sylhet।* দ্রুত প্রশ্ন-উত্তর — উত্তর বলে দেবেন না।

| শিক্ষক বলবেন | প্রত্যাশিত উত্তর |
|---|---|
| "Cat কী — একটি প্রাণীর নাম নাকি একটি কাজের নাম?" | একটি প্রাণীর **নাম** |
| "Book কী?" | একটি জিনিসের নাম |
| "Aisha কী?" | একজন মানুষের নাম |
| "Sylhet কী?" | একটি স্থানের নাম |
| "এই চারটির মিল কোথায়?" | সবই কোনো কিছুর **নাম** |
| "মানুষ, প্রাণী, জিনিস ও স্থানের নামকে কী বলে?" | **Noun (বিশেষ্য)** |

**শিক্ষক বলবেন (সংযোগ):** "ঠিক। এগুলো সবই **Noun**। আজ আমরা দেখব — একটির বেশি হলে noun কীভাবে বদলায়।"

---

### ধাপ ৩ — Plural concept: Remember (১০–২৩ মিনিট)

**করণীয়:** বোর্ডে দুটো কলাম আঁকুন: **Singular (একটি)** | **Plural (একটির বেশি)**। নিচের ৫টি pair একে একে মডেল করুন, তারপর ৭ জন শিক্ষার্থীকে oral drill-এ ডাকুন।

**শিক্ষক বলবেন (model):** "দেখো — cat। এটি একটি — **one cat**। এখন দুটো হলে কী হবে? শেষে **–s** যোগ করি — **two cats**। বোর্ডে লিখি।"

বোর্ডে লিখুন:

| Singular (একটি) | Plural (একটির বেশি) |
|---|---|
| one cat | two cats |
| one bird | two birds |
| one book | two books |
| one pen | two pens |
| one tree | two trees |

**Oral drill — ৭ জনকে আলাদাভাবে ডাকুন:**

| শিক্ষক বলবেন | প্রত্যাশিত উত্তর |
|---|---|
| "সবাই বলো: one cat, two ___" | **cats** |
| "[Nusair], one bird, two ___?" | **birds** |
| "[Aisha], one book, three ___?" | **books** |
| "[Yusuf], one pen, two ___?" | **pens** |
| "[Raima], one tree, four ___?" | **trees** |
| "[Abdullah], one cat, many ___?" | **cats** |
| "[Porshi], one bird, five ___?" | **birds** |

**শিক্ষক বলবেন (নিয়ম সংক্ষেপ):** "নিয়ম: **একটির বেশি → noun-এর শেষে –s যোগ করো।** এটাই **Plural (বহুবচন)**।"

*শিক্ষক নোট: যদি exam paper-এর "Cats catch mice" বা "My uncle has two sons" বাক্য নিয়ে কেউ জিজ্ঞেস করে — mice ও children বদলায় ভিন্নভাবে। বলুন: "এগুলো special word — পরে শিখব।" Graded নয়।*

### ধাপ ৪ — New Word Routine S1: duck · frog · lion · fish · parrot (২৩–৩৫ মিনিট)

**করণীয়:** প্রতিটি শব্দের জন্য See → Hear → Say → Mean → Frame (প্রায় ২.৫ মিনিট)। ৭ জনকে পর্যায়ক্রমে ডাকুন।

#### duck
| Step | শিক্ষক করবেন | শিক্ষার্থী করবে |
|---|---|---|
| **See** | বোর্ডে লিখুন: **duck** | দেখে |
| **Hear** | "Duck. Duck." (দুইবার স্পষ্টভাবে) | শোনে |
| **Say** | "সবাই বলো — duck. আবার — duck." তারপর "[Abdur Rahim], বলো।" | Chorally × ২; তারপর individually |
| **Mean** | "Duck মানে **হাঁস**। বলো — হাঁস।" | হাঁস |
| **Frame** | "This is a duck." (বোর্ডে লিখুন) → "তোমরা: A duck is a ___." | A duck is an animal. *(সাহায্য করুন: "animal")* |

#### frog
| Step | শিক্ষক করবেন | শিক্ষার্থী করবে |
|---|---|---|
| **See** | বোর্ডে লিখুন: **frog** | দেখে |
| **Hear** | "Frog. Frog." | শোনে |
| **Say** | "সবাই — frog. [Nusair], বলো।" | Chorally; individually |
| **Mean** | "Frog মানে **ব্যাঙ**। বলো — ব্যাঙ।" | ব্যাঙ |
| **Frame** | "This is a frog." → "তোমরা: A frog is a ___." | A frog is an animal. |

#### lion
| Step | শিক্ষক করবেন | শিক্ষার্থী করবে |
|---|---|---|
| **See** | বোর্ডে লিখুন: **lion** | দেখে |
| **Hear** | "Lion. Lion." | শোনে |
| **Say** | "সবাই — lion. [Aisha], বলো।" | Chorally; individually |
| **Mean** | "Lion মানে **সিংহ**। বলো — সিংহ।" | সিংহ |
| **Frame** | "A lion is a big animal." → "তোমরা: A lion is a ___ animal." | big / strong *(যেকোনো একটি গ্রহণযোগ্য)* |

#### fish ⚠
| Step | শিক্ষক করবেন | শিক্ষার্থী করবে |
|---|---|---|
| **See** | বোর্ডে লিখুন: **fish** | দেখে |
| **Hear** | "Fish. Fish." | শোনে |
| **Say** | "সবাই — fish. [Yusuf], বলো।" | Chorally; individually |
| **Mean** | "Fish মানে **মাছ**। বলো — মাছ।" | মাছ |
| **Frame** | "This is a fish." → "তোমরা: A fish is a ___." | A fish is an animal. |

*শিক্ষক নোট: fish-এর plural হয় fish — "fishes" নয়। এ কারণে fish plural drill বা CW/HW-এ আসবে না। শুধু বানান ও অর্থ পরীক্ষায় আসে।*

#### parrot
| Step | শিক্ষক করবেন | শিক্ষার্থী করবে |
|---|---|---|
| **See** | বোর্ডে লিখুন: **parrot** | দেখে |
| **Hear** | "Parrot. Parrot." | শোনে |
| **Say** | "সবাই — parrot. [Raima], বলো।" | Chorally; individually |
| **Mean** | "Parrot মানে **টিয়া**। বলো — টিয়া।" | টিয়া |
| **Frame** | "A parrot is a bird." → "তোমরা: I see a ___." | I see a parrot. |

### ধাপ ৪ — Guided plural practice: Understand → Apply (১৮–৩৫ মিনিট)

#### অংশ ক — Choose correct form (guided, oral) (১৮–২৬ মিনিট)

**করণীয়:** বোর্ডে একটি বাক্য লিখুন; শিক্ষার্থীরা bracket থেকে সঠিক শব্দ বাছে। প্রথমটি একসাথে করুন; বাকিগুলো পর্যায়ক্রমে।

| বাক্য (বোর্ডে লিখুন) | সঠিক উত্তর | কেন |
|---|---|---|
| Nusair has one (bag / bags). | **bag** | one = একটি → –s নয় |
| I see two (bird / birds) in the tree. | **birds** | two = দুটো → –s |
| There are three (book / books) on the desk. | **books** | three → –s |
| Aisha has one (cat / cats). | **cat** | one → –s নয় |
| We see five (tree / trees). | **trees** | five → –s |

**প্রথম বাক্য model করুন:** "দেখো — 'one bag'। এক মানে একটি — তাই শেষে –s নেই। উত্তর: bag।"

| শিক্ষক বলবেন | প্রত্যাশিত উত্তর |
|---|---|
