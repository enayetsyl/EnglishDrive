# Class 1 English — Teacher Delivery Sheet
## Block 01: Word (W1 · ১–৩ জুলাই · ৪টি সেশন, ৩৫ মি.)

> **এই শিটটি কী:** শুধু ক্লাসে পড়ানোর জন্য — teaching script, board work, delivery sequence ও target উদাহরণ। উত্তর-চাবি, dictation শব্দ-তালিকা ও build-নোট এতে নেই (সেগুলো master ফাইলে)।

**Delivery language:** Bangla-led (English grammar terms + target words English-এ)।
**Block 01-এর মূল কথা:** এটি **শব্দভান্ডার-ব্লক** — ব্যাকরণ-বিশ্লেষণ নয়। শিক্ষার্থীরা এই সপ্তাহের ৮টি শব্দ **শুনে · বলে · অর্থ বুঝে · বাক্যে বসিয়ে** শিখবে। শব্দ-শ্রেণি (Noun/Verb) নাম দিয়ে শেখানো হয় না। **এই সপ্তাহে Clue Card নেই।**

---

## Learning outcomes (plain form)

- ৮টি শব্দ শুনে চিনতে ও মুখে বলতে পারা: father · mother · brother · sister · cat · dog · bird · cow (সবই noun)।
- দেওয়া শব্দের **বাংলা অর্থ** লেখা; dictation থেকে **বানান** লেখা; একটি অক্ষর দিয়ে ২টি শব্দ লেখা।
- January · February · March — বলা ও বানান করা (১২ মাসের চার্ট দেয়ালে)।
- নিজে একটি সহজ বাক্য তৈরি (self-try — সর্বোচ্চ Bloom-মুহূর্ত)।

**Bloom shape:** Remember/Understand প্রধান → simple Apply → simple Create (শুধু self-try)। এর উপরে নয়।

## New Word Routine — প্রতিটি নতুন শব্দে (See → Hear → Say → Mean → Frame · প্রতি শব্দ ২–৩ মিনিট)

| ধাপ | কী করবেন | নমুনা (bird) |
|---|---|---|
| **① See** | শব্দটি বোর্ডে স্পষ্ট করে লিখুন | *bird* |
| **② Hear** | দুইবার বলুন | "Bird. Bird." |
| **③ Say** | দলগত ×২, পরে একক | "All together — bird. Again — bird. Nusair, say it." |
| **④ Mean** | বাংলা অর্থ বলুন; শিক্ষার্থীরা পুনরাবৃত্তি করবে | "Bird means পাখি. বলো — পাখি।" |
| **⑤ Frame** | একটি সহজ বাক্যে বসান; শিক্ষার্থীরা ফাঁক পূরণ করবে | "This is a bird." → "A bird is an animal." → "I see a ___." |

> **নিয়ম:** এক সেশনে **৩–৪টি** শব্দ — একসাথে ৮টি নয়। সব Frame **present tense**; কোনো past tense নয়।

# Session 1 — W1 diagnostic + প্রথম ৪টি শব্দ (father · mother · brother · sister)

**উপকরণ:** ১২ মাসের চার্ট; বোর্ড-মার্কার; ১টি ছবি; একটি কলম ও টেবিল; diagnostic রেকর্ড-শিট।

**ধাপ ১ — Track A (০–৫ মিনিট):** ৬টি ধাপই দলগত (choral), ~৪৫ সে./ধাপ; ৭ জনের ক্লাসে ৫ মিনিটেই হয়। ধাপ ⑥ = January · February · March।

**ধাপ ২ — W1 diagnostic (৫–২০ মিনিট, মৌখিক):** এটি **যাচাই — শেখানো নয়।** ৭ জনের প্রত্যেককে পাঁচটি check এক এক করে করুন। ঠিক = ✓, দুর্বল = ~, না পারলে = ✗। **উত্তর বলে দেবেন না।**

| যাচাই | শিক্ষক বলবেন | টপিক |
|---|---|---|
| Noun | *"একটা নামের শব্দ বলো।"* | Noun ID |
| Naming sentence | ছবি দেখিয়ে: *"This is দিয়ে একটা বাক্য বলো।"* | Naming sentence |
| Article | *"apple-এর আগে a না an? book-এর আগে?"* | Article a/an |
| Preposition | কলম টেবিলের উপর রেখে: *"Where is the pen? পুরো বাক্যে বলো।"* | Place sentence |
| Description | ছবি দেখিয়ে: *"একটা describing word দিয়ে এই ছবির কথা বলো।"* | Adjective |

**Per-student question bank (৭ জন — প্রতি শিক্ষার্থীর আলাদা আইটেম):**

| # | ① Noun | ② Naming | ③ Article | ④ Preposition | ⑤ Description |
|---|---|---|---|---|---|
| 1 | book | cat → *This is a cat.* | **apple** → an | pen **on** the table | tree → *big* |
| 2 | pen | bird → *This is a bird.* | **book** → a | pen **under** the chair | cat → *small* |
| 3 | bag | book → *This is a book.* | **egg** → an | pen **in** the bag | hands → *clean* |
| 4 | door | pen → *This is a pen.* | **cat** → a | book **on** the chair | Nusair → *good* |
| 5 | chair | tree → *This is a tree.* | **orange** → an | book **under** the table | flower → *red* |
| 6 | board | flower → *This is a flower.* | **bird** → a | book **in** the bag | tree → *tall* |
| 7 | clock | ball → *This is a ball.* | **umbrella** → an | pen **on** the book | wall → *white* |

> **ব্যাখ্যা (an কেন):** স্বরবর্ণ-ধ্বনি → **an** (an apple, an egg); ব্যঞ্জন-ধ্বনি → **a**। এই সপ্তাহের ৮টি শব্দে স্বরবর্ণ-শুরু নেই, তাই বাইরের পরিচিত শব্দ দিয়ে *an* যাচাই।
> **ফলাফল ব্যবহার:** বেশি ✗ যে টপিকে — পরের ব্লকে বেশি সময় নিয়ে re-walk (Noun → B2/B3 · Article → Thursday drill · Preposition → B7 · Description → B4)।

**ধাপ ৩ — New Word Routine: father · mother · brother · sister (২০–৩৫ মিনিট):**

| শব্দ | অর্থ | Frame (present tense) | শিক্ষার্থী পূরণ করবে |

# Session 2 — বাকি ৪টি শব্দ (cat · dog · bird · cow) + বানান অনুশীলন

**উপকরণ:** ১২ মাসের চার্ট; বোর্ড; শিক্ষার্থীদের খাতা।

**ধাপ ১ — Track A (০–৫ মিনিট):** ৬টি ধাপই দলগত।

**ধাপ ২ — পুনরালোচনা (৫–৮ মিনিট):** গতকালের ৪টি শব্দ দ্রুত ঝালাই — অর্থ ঢেকে শব্দ দেখান, শিক্ষার্থীরা বাংলা অর্থ বলবে।

**ধাপ ৩ — New Word Routine: cat · dog · bird · cow (৮–২২ মিনিট):**

| শব্দ | অর্থ | Frame (present tense) | শিক্ষার্থী পূরণ করবে |
|---|---|---|---|
| **cat** | বিড়াল | "A cat is clean." | "I see a ___." |
| **dog** | কুকুর | "A dog is an animal." | "A ___ is an animal." |
| **bird** | পাখি | "A bird can fly." | "A ___ can fly." |
| **cow** | গরু | "A cow is a big animal." | "A ___ is a big animal." |

> **মূল্যবোধ-নোট (কুকুর):** কুকুর শুধু **"একটি প্রাণী"** হিসেবে আসবে — ঘরে পোষা প্রাণী হিসেবে **নয়** (ফিকহে কুকুর অপবিত্র)। bird · cat · cow — আল্লাহর সৃষ্টি হিসেবে কৃতজ্ঞতার ভাবে ("A cow is a gift from Allah")। সব বাক্য present tense।

**ধাপ ৪ — বানান অনুশীলন: copy → cover → write (২২–৩৫ মিনিট):** বোর্ডে *cat* লিখুন। "৩ বার দেখে দেখে লেখো (copy)। ঢেকে দাও (cover)। না দেখে লেখো (write)।" একটি শব্দ পুরো মডেল করুন, তারপর শিক্ষার্থীরা ৮টি শব্দেই করবে।

**সেশন শেষ:** "কাল আমরা worksheet করব আর নিজে একটা বাক্য লিখব; বাড়ির কাজও দেব।"

# Session 3 — Classwork + Self-try + হোমওয়ার্ক

**উপকরণ:** CW worksheet কপি; বোর্ড; self-try ফ্রেম; HW worksheet + অভিভাবক-নোট।

> **CW/HW আইটেম নিজের নিজের extract-শিটে (আলাদা)** — এই শিটে ছাপা হয় না।

**ধাপ ১ — Track A (০–৫ মিনিট)।**

**ধাপ ২ — Classwork Worksheet (৫–২১ মিনিট):** প্রথম ২টি করে আইটেম একসাথে করুন, বাকিটা শিক্ষার্থীরা নিজে করবে; ঘুরে ঘুরে দুর্বলদের সাহায্য করুন। (Part A: বাংলা অর্থ লেখা · Part B: অক্ষর দিয়ে শব্দ লেখা।)

**ধাপ ৩ — Self-try (Create) (২১–২৮ মিনিট):**
- **ফ্রেম:** *"A ___ is ___."* — শিক্ষার্থী এই সপ্তাহের ৮টি শব্দ থেকে যেকোনো একটি নিয়ে ১টি বাক্য লিখবে।
- **স্ক্রিপ্ট:** (১) *"এখন তুমি নিজে চেষ্টা করবে। আমি সাহায্য করব না। এটা তোমার নিজে ভাবার সময়।"* (২) বোর্ডে ফ্রেম লিখুন, একবার পড়ে শোনান। (৩) শিক্ষার্থীরা **চুপচাপ** নিজে লিখবে। (৪) ২–৩ জন পড়ে শোনাবে; শুধু accuracy-তে সংক্ষিপ্ত মন্তব্য। (৫) খাতা সংগ্রহ করুন; ১০-নম্বর রুব্রিকে মূল্যায়ন।
- **ভালো উত্তরের নমুনা:** *A bird is an animal. · A cat is clean. · A cow is a gift from Allah. · A cow is big.*

> **⚠ Self-try কখনো বাদ দেবেন না।** সময় কম হলে worksheet-এর শেষ আইটেম কাটুন — self-try নয় (এটিই ব্লকের সর্বোচ্চ Bloom-মুহূর্ত)।

**ধাপ ৪ — হোমওয়ার্ক বিতরণ (২৮–৩৫ মিনিট):** HW + অভিভাবক-নোট প্রত্যেককে দিন: "বাড়িতে ৮টি শব্দ বানান অনুশীলন, অর্থ লেখা, ৩টি মাস লেখা, আর অভিভাবক বৃহস্পতিবার dictation পড়াবেন।"
**HW মূল্যায়ন (ক্লাসের বাইরে):** বানান/অর্থ/মাস ঠিক কি না। **✓ / ✓+ / ✓-** + ছোট মন্তব্য (অভ্যাস গড়াই লক্ষ্য; টেস্টের নম্বরে নয়)।

# Session 4 (বৃহস্পতিবার) — সাপ্তাহিক Performance Test (৩৫ মিনিট)

**ধাপ ১ — Track A (০–৫ মিনিট)।**

**ধাপ ২ — টেস্ট-প্রিভিউ (৫–৭ মিনিট):** সবচেয়ে নতুন ৩টি শব্দ (*dog · bird · cow*) বোর্ডে লিখুন; See → Hear → Say → Mean (**Frame নয়**)। এতে নিশ্চিত হয় কোনো শব্দ প্রথমবার টেস্ট-কাগজে আসছে না।

**ধাপ ৩ — Performance Test (৭–৩৫ মিনিট):** test paper বিতরণ (student-facing extract আলাদা)। **Part A dictation আপনি পড়বেন** — প্রতিটি শব্দ **দুইবার**, ধীরে।

**Performance Test procedure (student-facing):**
- **Part A — Spelling dictation [৫]** · **Part B — Bengali meanings [৫]** · **Part C — 12 months [৩]** · **Part D — Letter-words [২]** → vocabulary মোট **১৫**।
- **Part E — Embedded exam-format drills [৭]** (Noun ID 3 · Article 2 · Preposition 2) — **আলাদা ট্র্যাক**, retention gate-এ গণনা নয়।

> dictation শব্দ-তালিকা master (teacher copy)-তে; এই শিটে ছাপা নেই।

**ধাপ ৪ — মূল্যায়ন ও retention gate (পরের সেশনের আগে):**
- ১৫-নম্বর vocabulary যোগ করুন → শ্রেণির গড়।
- **retention gate:** গড় **≥৮০%** ⇒ পরের সপ্তাহে batch বাড়ান (৮→১০) · **৬৫–৭৯%** ⇒ ধরে রাখুন, ২–৩টি দুর্বল শব্দ বদলান · **<৬৫%** ⇒ batch ছোট করুন ও S1-এ দুর্বল শব্দ পুনরায় শেখান।
- Part E (৭) আলাদা রেকর্ড করুন — W1 diagnostic-এর follow-up।

## Self-try — free-thinking rubric (১০ নম্বর · শিক্ষক মূল্যায়ন করবেন)

এক-বাক্যের self-try — রুব্রিক **সমানুপাতে** পড়ুন; সঠিক, সুবিন্যস্ত, ইসলামি-ইতিবাচক এক বাক্য দৈর্ঘ্য নির্বিশেষে পূর্ণ নম্বর।

| Criterion | Marks | Class 1-এ কেমন দেখাবে |
|---|---|---|
| Content accuracy (শব্দ ফ্রেমে সঠিক) | 3 | *"A bird is an animal."* |
| Reasoning (নিজের পছন্দ ব্যাখ্যা — বাংলায়ও চলবে) | 3 | *"পাখি একটা প্রাণী, তাই animal লিখেছি।"* |
| Organisation (বড় হাতে শুরু; শেষে full stop; পরিষ্কার) | 2 | *A* দিয়ে শুরু, শেষে *.* |
| Islamic / value alignment | 2 | *A cow is a gift from Allah.* |
| **Total** | **10** | |

*(Class 1-এ শব্দ-শ্রেণি নাম দেওয়ার criterion নেই — সেটি Class 3-এ যোগ হয়।)*

## Values reminders (এই ব্লকে)

- ✓ ব্যবহার করুন: bird · cat · cow — আল্লাহর সৃষ্টি; family — father/mother/brother/sister।
- ✓ ইসলামি anchor (present tense): *"A cow is a gift from Allah." · "We drink milk from the cow." · "A bird is an animal."*
- ✗ কুকুর ঘরের ভেতরে পোষা প্রাণী হিসেবে নয় — শুধু "একটি প্রাণী"।
- ✗ কোনো past tense শিক্ষার্থী-মুখী বিষয়বস্তুতে নয়।
- ✗ NCTB বইয়ের চরিত্র-নাম (Raju, Sheela …) নয় — শুধু house-style নাম।
- ✗ non-mahram পুরুষ-নারী নাম একসাথে কোনো বাক্যে নয়।
