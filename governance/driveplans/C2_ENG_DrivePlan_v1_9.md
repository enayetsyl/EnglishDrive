## Summary (read this first — 60 seconds)

This is the Class 2 cut of the drive, built down from the validated Class 3 pilot. Grammar runs as a **cumulative track in spine order, bottom-up**, but Class 2 is **pre-grammatical by book** — the NCTB Class 2 text teaches phonics, vocabulary and communication, not formal grammar. So the spine here is deliberately **lighter and shorter than Class 3 (12 blocks, not 14)**, and it grows **from communication to formal labels**: children first talk in sentences, then learn the *kinds* of words, then build, join and punctuate sentences, and finally fill a **guided paragraph frame**.

Every grammar rung below is either **in the Book/TG** or a **small, ruled-in "bridge"** the principal accepted — because the school's own Mohammadpur papers test a near-full Class-3 grammar spine that the Class 2 book does not contain. Two topics the papers test were **postponed to Class 3** (noun gender; free composition) as beyond Class 2 readiness, with a paired exam-revision recommendation to the school.

Three things hold every block together: practice **reuses words students already hold** (the POS-tagged pool, front-loaded); every block **ends in a self-construction (self-try) task** marked on the rubric; and every block carries the **New Word Routine** at the Class 2 level — *recognise a word's job, then use it* (Remember/Understand-heavy, no dual-job). All examples are authored in-house to Salafi/athari values in the school's own house style.

The load-bearing sections for building File 3 are **§2 (depth caps)** and **§4 (the block-by-week schedule)**.

## §1 — What this plan is

The Class 2 grammar track is **foundational and cumulative**: it builds the lowest rungs of the spine in simple language, in the order each rung prepares the next. **First-appearance teaching:** every grammar concept receives its first explicit instruction, to its intended depth (§2 cap), at the point it first appears in the spine; no concept's initial teaching is deferred to a later revision or consolidation block, and the re-walk step (Rule 2) is a bridge for students who already hold the lower rung, not the place a rung is first taught. It is **book-bounded with a ruled-in bridge** — every structure below is either evidenced in the NCTB *English for Today* Class 2 text / Teachers' Guide, **or** is a small bridge item the principal explicitly accepted because the school's Half-Yearly / Annual paper tests it and it fills a genuine gap, serves as a prerequisite, and is manageable for Sylhet learners. No structure is taught **only** because Mohammadpur teaches it, or **only** because it appears in an exam.

The 11 grammar blocks below are the Class 2 inventory ruled in this build cycle. File 3 builds them **one block at a time, in spine order**, each as a self-contained teacher-facing file.

## §2 — The Class 2 grammar spine cut (rung-by-rung, with depth caps)

The **cap** is the guardrail: teach *to* the cap, never past it. "Re-walk" = a fast revision of the lower rung before the block's own work. **(B)** marks a ruled-in **bridge** item (kept light); items marked **→C3** are postponed and must **not** appear.

| # | Block | Teach to this depth (cap) | Do **not** go beyond (guardrail) |
|---|---|---|---|
| 1 | **Word & Sentence** | A word has a **meaning** and a **job** — naming word / doing word. A sentence is a complete thought; it **starts with a capital and ends with a full stop**. Build & identify a simple sentence (naming part + doing part). Question words **what / where / who**. | No word-class theory beyond naming/doing; no describing/position labels yet; no clause or subject–predicate analysis. |
| 2 | **Naming Words: Common & Proper + Capitals** *(B: recognition)* | Naming words name people, places, things. **Special names** — people, places, **Allah**, **Bangladesh**, **day-names** — start with a **capital letter**. **Recognition only:** find the special name / the common naming word. Capital rule on names, sentence-start, and **I**. | **Recognition only** — **no** taxonomy, **no** "define common/proper noun," **no** categories to memorise (principal ruling). |
| 3 | **a / an / the** | **an** before a word starting with a **vowel letter** (a, e, i, o, u) — an egg, an apple, an engineer; **a** before the rest — a book, a lake; **the** for a specific/known thing (the sun, the Quran, the Meghna). Fill in a / an / the. | Keep to the **simple vowel-letter rule** — it fits every word the Class 2 paper uses; **avoid sound-exception words** (hour, honest, university) at Class 2; no zero-article rules; no definiteness theory. |
| 4 | **Noun — Gender (masculine / feminine / common)** *(distributed W3–W4 strand)* | Naming words can tell **male** (**masculine**) or **female** (**feminine**); some can be **either** (**common** — friend, teacher, student, cousin, baby). **W3:** recognition + introductory graded production. **W4 (Sunday):** production consolidation + common gender + self-try. Graded set runs to **11 production pairs**. W3 Performance Test is a standalone file (`C2_ENG_W3_PerformanceTest`); W4 gender is tested in the combined W4 PT. | **No neuter** (Class 3 adds the fourth category); no edge-case common-vs-neuter theory; keep to the taught pairs + the 7-word common set. *(Renumbered from bridge item to standalone Block 4 — Principal ruling 2026-07-26; supersedes the former "no common gender / no production beyond circling" caps.)* |
| 5 | **One → Many: Plurals** *(B: 1–2 irregular)* | Regular **-s** (book→books), **-es** (class→classes, watch→watches), **-y→-ies** (city→cities, story→stories). **Plus 1–2 irregulars only:** child→children, tooth→teeth (or man→men). Write the plural. **W4: Plurals taught Mon–Tue; Wednesday consolidates Gender + Plural; Thursday PT is combined Gender + Plural.** | Regular focus; **no long irregular lists**; no countable/uncountable rules; **-f→-ves held for Class 3**. |
| 6 | **Doing Words: Verbs + am/is/are + have/has** *(load peak — 2 weeks)* | Doing words (the book's verb spine: read, write, play, go, come, eat, drink, wash, help, cook…). **Simple present** with **light subject agreement** (he reads / they read). **am / is / are** (I am, he is, they are). **have / has** (I have, she has). Fill the correct doing word / be / have-has; match to make a sentence. | Agreement kept to **subject-number only**; **no past / future**; no negative/question transforms; **no continuous**; no tense theory. |
| 7 | **Describing Words: Adjectives & Opposites (+ owning words)** | Describing words tell **what kind** (big, small, hot, cold, new, old, clean, kind) and **whose** — the **owning words my, his, her, our, their** that come before a naming word (*my book, his pen*). **Opposites** (big↔small, hot↔cold, new↔old, long↔short, dark↔light). Identify a describing word; write its opposite; pick the right owning word. **W7 S1 opens with a 10-min demonstrative re-walk before Adjective content begins — see Bridge items below.** | **No comparative / superlative** (bigger/biggest); no degree; opposites only. Owning words taught **by function** (come before a naming word; show who owns) — **not** labelled "pronoun"; stand-alone **mine/hers/theirs not introduced**. |
| 8 | **Pronouns** *(B: object light)* | **Personal pronouns** that **take the place of a naming word** — subject I, he, she, it, we, they; **object** him / her / them (light). Fill the right pronoun in **small items**. | Object forms **recognition only**; **no large cloze** (≤5 short blanks, not the 10-blank paper cloze). **Owning words (my/his/her) are taught in Block 7, not here — aligned with Class 3.** |
| 9 | **Position Words: Prepositions** *(B: time light)* | **Place words** — in, on, under, near, behind, beside. **Light time words** — at (at 12), in (in 2018), to (to school). Fill the correct position word. | **Place is core**; time forms stay **light / recognition**; no prepositional-idiom or abstract use. |
| 10 | **Building Sentences: Punctuation** *(B: comma + ! light)* | **Capital** at sentence-start, on special names, and on **I**; **full stop**; **question mark**. Light: **comma in a list**, **exclamation mark**. Rewrite a sentence with correct capitals + stop marks. | Keep to the Annual Q8 scope; comma/! kept **light**; **no semicolon / colon / quotation marks** (those are Class 3). |
| 11 | **Joining Sentences: and / but** | Join two simple sentences with **and** (adds) / **but** (contrasts): "I like rice **and** I like fish." / "It is small **but** it is clean." Join the pair. | **Two connectives only** (and, but); **no so / or / because** (Class 3); no subordinate clauses. |
| 12 | **Guided Paragraph** *(B)* | A **4–5-sentence guided frame** on a familiar topic (My Family / My School / My Daily Life): opening + 2–3 fact sentences + closing — e.g. "My family is small. There are five members. My father is a teacher. My mother cooks food. I love my family." | **Frame-filled, not** free 8–10-sentence composition (Class 3); not creative writing. |

**Block count: 12** (was 11 before the 2026-07-26 gender renumbering — Gender inserted as standalone Block 4, Plurals-onward +1).

**Postponed to Class 3 (excluded from this spine — do not build at Class 2):** **free composition** (open paragraph) — sits on the Class 3 spine and exceeds Sylhet Class-2 readiness; the school's paper carries a **paired exam-revision recommendation** (§7). *(Noun gender is no longer postponed — it is taught as Block 4 above, masculine/feminine/common; the fourth category, neuter, remains Class 3.)*

**Re-walk rule (Rule 2).** Each block opens by quickly re-touching the rungs below it (Block 5 re-touches "naming word" before plurals; Block 10 re-touches Block 2's capital rule before punctuation), so a child who missed an earlier rung still has a footing.

## §5 — Vocabulary reuse base (which words a block may use)

**Graded items** draw **only from words held by that week** — fresh batch to date + the already-taught early-unit base + the universal core. A student is never graded on a word not yet taught. **Teaching examples** (worked examples, board illustration, teacher talk) **normally use held words**, but may use a **common, age-appropriate word not yet in the held set** where it makes a clearer or more natural example (Principal ruling); any such word is still curation-screened (charter §H.9) and bound by the sacred-word guard (§H.3), and is never the answer in a graded item. POS tags in the pool route each word to its matching block.

- **Routing (built at File 2):** **naming words** → Blocks 1–5 (Word, Common/Proper, Article, **Gender**, Plural); **doing words** → Block 6 (Verb); **describing + owning words** → Block 7 (Adjective + my/his/her); **position words** → Block 9 (Preposition). Personal pronouns and conjunctions need no new pool words — pronouns reuse held nouns (as objects), conjunctions reuse held sentences (to join).
- **Pool status:** the Class 2 POS-tagged pool is **not yet built**. File 2 builds it from the NCTB Class 2 textbook (Units 1–10) — the uploaded `Class_2_English.pdf` is **image-only (OCR required)**, same method as the Class 3 pool. Until then, §4 batch sizes are planned shapes, not fixed counts.
- **Sylhet adaptation:** keep each week's new-word load **below** the Class 3 equivalent; let the retention gate (§3) drive the pace, not the calendar.

## §6 — Bloom application (Class 2)

**Band (REF-18 §4.1, Class 2):** dominant **Remember, Understand, simple Apply**; suitable exposure **simple Analyze (grouping)**. Methods: classify, match, use words, simple sentence answers. **Do not over-demand** — keep language and context simple.

**Indicative chapter-scope mix (REF-18 §4.2, Class 1–2):** Remember **35–45%** · Understand **30–40%** · Apply **15–25%** · Analyze **0–10%** · Evaluate **0–5%** · Create **0–5%**. These describe the **whole block**, not a single item.

**Climb within each block (Rule 5 / REF-18 ready-check):** open at **Remember/Understand** (recognise the word's job; say the rule), move to **simple Apply** (use it on given items in the exam format), touch **simple Analyze** only as grouping/matching where the band allows, and close at a **small Create** — the self-try task (one sentence). Run REF-18 §6 watch-outs before finalising any set — a high-level verb does not make a high-level item; copying is not Remember.

**New Word Routine on the same logic:** Class 2 sits at **Recognise-and-Use** — name a word's **job** (naming / doing / describing) and then use it. **No dual-job at Class 2** (dual-job is introduced at Class 3, fluency at Classes 4–5; §8).

## §8 — New Word Routine staging (Class 2)

**Rung (REF-18 / charter §N):** Class 2 = **Recognise-and-Use** — *Meaning → **Job** → Use*. Name the word's job from the **clue card** (naming → naming word; doing → doing word; describing-a-naming-word → describing word), then use it in the current block's structure. A one-page clue card accompanies the File 3 set as a standing reference.

**No dual-job at Class 2 (charter §N).** Class 2 stays at single-job recognition — a word has **one** job in the child's eyes for now. The "a word's job comes from its place in *this* sentence" idea is **introduced at Class 3**, drilled at Classes 4–5. Do **not** put minimal-pair (noun↔verb) items in Class 2 blocks.

**Where Blocks 1–2 sit:** Block 1 **introduces the routine and the clue card** on naming vs doing words; Block 2 **uses** it inside common/proper recognition. Describing-word sorting joins at Block 7.

## §9 — Free-thinking close + marking rubric

Every block ends with a **self-construction (self-try) task** (charter §I): the student writes **their own one sentence** using the block's rule **and** a word from the current set, after first **naming the word's job** and then **giving a one-sentence reason for that word-job choice** (either language, or mixed — tied specifically to the job just named). Frame it **anchored**, never open-ended ("Write your own sentence about your family using a **doing word** you learned, name its job, say why, and circle the doing word" — not "write anything").

**Rubric** = Charter §I.3 — **4 marks, four criteria at 1 mark each, uniform across all five classes**. Islamic/value alignment is **not** a scored criterion (Charter §I.3, Run Book §13.1): §H binds all authored material in full, but a religiously neutral on-topic student answer earns full marks, and a §H conflict is flagged as a values matter rather than marked down. Each criterion scores 1 or 0; no partial credit.

| Criterion | Marks |
|---|---|
| Content accuracy (rule used correctly) | 1 |
| Reasoning *(এক বাক্যে কারণ বলা যায় — one sentence, either language or mixed, tied to the word-job identified)* | 1 |
| Organisation | 1 |
| **Correct word-job placement** *(naming / doing / describing)* | 1 |
| **Total** | **4** |

*Class 2's Neatness & mechanics criterion is retired under Charter v1.3 §I.4; the uniform four-criteria set replaces it.*

*Scaling note:* Reasoning is **restored** at Class 2 as a simple, anchored 2-mark criterion — one sentence, either language or mixed, tied specifically to the word-job just identified — sitting between Class 1's open/informal Reasoning and Class 3's evaluated Reasoning (Charter §I.4). This supersedes the earlier no-Reasoning, 8-mark shape. Teachers read the rubric proportionally; the criteria are the point, not the raw total.
